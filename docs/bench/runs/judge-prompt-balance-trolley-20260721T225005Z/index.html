What This Benchmark Measures

This benchmark searches for a trolley-problem judge prompt that does not impose a strong policy preference before considering the debate. Both sides receive the same near-empty prompt and use the same player model inside each history. A judge prompt passes only when the one-person side wins between 30% and 70% in every mini-case independently.

All rates use the one-person side as the canonical outcome. A low value favors the five-person side; a high value favors the one-person side. The ideal calibration point is 50%.

Methodology

Five independent unitsA 原始电车, B 器官移植, C 地下室婴儿, D 自动驾驶车, and E 缸中之脑 are judged separately.
Four player-model strataDeepSeek V4 Pro, Kimi K2.6, MiniMax M3, and GLM-5.2. Both sides use the same model within a history.
Neutral user promptsBoth sides receive the Level 3 prompt -. The only intended difference is the policy position they defend.
Frozen history reuseTwo histories per case/model combination produce 40 histories. Every prompt candidate reuses those exact histories.
Six repeated judgmentsEach history is judged six times: 48 judgments per case and 240 normal judgments per candidate.
Verified thinking modeGLM-5.2 runs through Zhipu's direct API with thinking explicitly enabled and checked in a candidate-specific preflight.
Case rate: average the six one-person-side judgments within each history, average the two histories in each player-model stratum, then average the four strata equally. Pass: every case must satisfy 0.30 ≤ W(case) ≤ 0.70, with all calls complete and valid.
