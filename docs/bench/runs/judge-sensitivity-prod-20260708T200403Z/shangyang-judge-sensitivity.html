Prompt-strength trend: positive means the varied side tends to win more as its prompt moves from Level 1 to Level 4; negative would mean it tends to win less; near 0 means the level changes do not form a consistent direction.
Prompt-strength trend（ignoring level 1) repeats the same prompt-strength trend calculation using only Level 2, Level 3, and Level 4.
Prompt-strength trend formula: let w_s(l) be the varied-side win rate for matchup s at Level l. For each matchup, T_s = [(w_s(2)-w_s(1)) + (w_s(3)-w_s(1)) + (w_s(4)-w_s(1)) + (w_s(3)-w_s(2)) + (w_s(4)-w_s(2)) + (w_s(4)-w_s(3))] / 6. The model metric is T = (T_商鞅 varied + T_甘龙 varied) / 2. Prompt-strength trend（ignoring level 1) applies the same pairwise-gap formula to L={2,3,4}.
Level 3 to 4 is the directional change in varied-side win rate from Level 3 to Level 4.
Level 3 to 4 formula: for each matchup, D_s = w_s(4) - w_s(3). The model metric is D = (D_商鞅 varied + D_甘龙 varied) / 2.
Fixed-history instability is a repeat-judge variance proxy for the same debate history; 0% means every repeat picked the same side, while a larger value means the repeated judgments split more often.
Total score is S = T + D - I, where T is Prompt-strength trend, D is Level 3 to 4, and I is Fixed-history instability. It is calculated from the unrounded metrics and displayed in percentage points.
