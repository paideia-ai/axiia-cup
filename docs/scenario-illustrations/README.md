# Scenario illustrations

This folder contains the approved images prepared for four Axiia Cup scenario introductions. Harbor Murder Jury and Honnoji each have two complementary images, so the folder contains six images in total. Most are black-and-white line illustrations; the Honnoji punishment scene is a cropped historical source image.

Keep the filenames stable when integrating them so documentation, design references, and frontend paths continue to match.

## Honnoji historical source

`honnoji-iron-fan-punishment.jpg` is cropped from the two-page illustration on pp. 132–133 of 『新編絵本太閤記』, edited by 歴史絵本研究会 and published by 主婦と生活社 in 1995. The accompanying account says that Nobunaga overturned the meal Mitsuhide had prepared and ordered an attendant to punish him with an iron fan.
