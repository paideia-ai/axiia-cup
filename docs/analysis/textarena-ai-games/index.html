The shared interface

No mouse. No controller. Just state → text → reward.

The games feel radically different, but the AI contract stays small: accept a textual observation and return a textual action. The hard part is understanding what the text means—and formatting the move so the environment accepts it.

01

Observation

A game prompt combines instructions with the current public state and any information private to that seat.

player_id, observation
02

Policy

An LLM, local model, human, or custom policy turns that observation into a strategic response.

agent(observation)
03

Action

Most structured games parse the first bracketed command. Conversational games may mix free text with a control token.

[Offer: 1 Ore -> 2 Wood]
04

Outcome

The environment applies the move, emits new observations, and ends with win/loss, rank, score, or task-completion reward.

done, info = env.step(action)

A useful progression

Start small. Add uncertainty. Then add society.

These five environments expose a model to increasingly rich coordination demands without jumping straight into the deepest rulesets.

  1. TicTacToe · parse the contract

    Open board, nine actions, immediate feedback. The cleanest integration smoke test.

  2. PigDice · manage risk

    Only roll or hold, but every choice trades expected value against catastrophic loss.

  3. SimpleNegotiation · price language

    Private valuations turn natural-language persuasion into measurable utility.

  4. Codenames · coordinate through roles

    Four agents must maintain team identity, asymmetric knowledge, and clue discipline.

  5. SecretMafia · reason about beliefs

    Hidden roles, public speech, night actions, voting, deception, and social memory collide.

Why “66,” when TextArena says “100+”?

The current source contains 97 callable game families: 31 solo, 49 two-player, and 17 multiplayer. This guide deliberately covers the 66 games in which multiple agents interact.

TextArena declares 242 base configurations and expands almost each one into normal, -train, and -raw forms—724 concrete environment IDs. Its older handbook still says “99,” so this guide treats the Python registry as the source of truth.
