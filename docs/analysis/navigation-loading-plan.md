# 页面切换加载优化

测量基线：`5891229`。最终工作分支已快进到 `2b5bd69`，包含期间合入的历史筛选修复。
Worktree：`axiia-cup-navigation-loading`；分支：`fix/navigation-loading`。

## 执行计划

1. **测量**：在本地 Chromium 中使用相同接口样本和固定延迟，记录首次进入、
   返回已访问页面、详情跳转的可用内容时间、重复请求、加载状态和外层布局变化。
   这是一组受控浏览器实验，不代表生产服务器延迟。
2. **消除重复等待**：共享查询缓存和进行中的请求；回访先显示数据、后台刷新；
   账号切换清空缓存，成功写入使相关查询失效；保持公共页面框架挂载。
3. **提前与分块加载**：导航及详情链接在悬停、聚焦和触摸时预取只读数据；
   历史列表不等待辅助角色信息，智能体主页不等待同侧智能体清单。
4. **过渡与验证**：按页面结构显示骨架，延迟 150ms 显示视觉等待提示；
   已有内容刷新不清空；短淡入不阻塞交互，尊重 reduced motion。
   运行格式、lint、类型、单元、Storybook、浏览器与构建检查。

## 视觉约束

沿用现有字体 Satoshi / Noto Sans SC 和颜色：背景 #0c0c0c、卡片 #161616、
占位 #1e1e1e、正文 #e8e8e8、次级文字 #aaaaaa、边框 #303030。
保持导航、标题、内容区左对齐和现有 1040px 最大宽度。卡片页占位对应双列
卡片，列表页对应横向行，详情页对应主内容块。仅一层淡入，不增加滑动、
跳动、逐卡片延迟或人为最低等待时间。

## 验收

- 返回已有数据的页面不再清空正文；后台刷新失败不销毁可用内容。
- 并发读取同一资源合并；预取只做 GET，不创建智能体或发起对战。
- 保存、删除、参赛设置、派发后不复用失效数据；账号数据隔离。
- 快速切换参数不会显示上一对象的详情。
- 首次加载、慢网、失败、空数据、移动端及 reduced motion 均可用。
- 记录前后实测结果与验证边界；后续已授权提交、推送、创建 PR 和预览；不包含生产部署。

## 进度与结果

四步已实施，导航专项浏览器验证全部通过。

### 实现

- 加入 TanStack Query 5 的内存查询缓存：目录和场景详情 30 秒新鲜期，普通
  列表 10 秒；无观察者的缓存保留 5 分钟。战报、编辑器草稿和版本读仍立即
  校验服务端，编辑器的草稿恢复和写入队列保持原有规则。
- 会话身份或权限变化清空缓存；按 credentials 区分访客和登录读取。
  相同 GET 合并进行中的请求，带独立 AbortSignal 的请求保持独立。
- 成功写入按资源组取消旧查询并失效缓存；请求代数同时覆盖 SSE 完局，避免
  重取再次接上写入前的旧请求。账号切换后晚到的旧响应不会进入新账号缓存。
- AppShell 和 RewardsProvider 在站内切页时保持挂载。公共场景、登录保护和
  管理员保护仍由独立路由守卫处理。
- 悬停、键盘聚焦和触摸可预取目录、清单、排名、通知、战报与智能体详情。
  开启节省流量时跳过预取；不预执行创建、保存或派发操作。
- 历史列表和角色信息分别加载；智能体主页的同侧清单不再阻塞核心内容。
- 首次等待用对应布局的骨架，150ms 后才显露；内容到达即显示，140ms 轻淡入
  不阻塞交互。已有内容后台更新时仅在顶栏下显示细条；失败保留旧内容并提供
  重试。401/403/404 表示会话、权限或资源已不可用，撤下缓存内容和操作。
- reduced motion 下不运行淡入或移动效果，仍保持 150ms 防闪提示门槛。

### 受控测量

工具：Chromium + Playwright，Vite 开发构建（含 React StrictMode）。接口使用
固定样本：目录延迟 650ms、历史和清单延迟 350ms，其余 50ms。步骤为场景
目录 → 历史 → 返回场景 → 场景详情；每次在新的浏览器上下文中执行。

| 指标 | 改动前两次 | 改动后多次运行范围 |
| --- | --- | --- |
| 进入历史到列表可见 | 921 / 937ms | 431–966ms |
| 返回场景到卡片可见 | 869 / 836ms | 76–90ms |
| 场景详情跳转 | 196 / 214ms | 191–300ms |
| 全流程目录请求 | 7 | 1 |
| 全流程积分请求 | 6 | 1 |
| 全流程通知订阅 | 3 | 1 |
| 跨区切换保留页头 DOM | 否 | 是 |

请求次数包含开发环境 StrictMode 的影响，不能当成生产请求次数。
首次完整页面打开受开发模块加载和外部字体响应影响，各次波动较大，未用来
宣称首屏提速。详情首次请求没有显著提速；预取完成和缓存回访才会直接复用。
历史页端到端计时仍有调度波动，因此不承诺固定提速比例；另用人工阻塞目录
响应的测试确认，目录未返回时对局列表已可见。以上不涉及生产服务器、真实
账号或部署后的性能证明。
