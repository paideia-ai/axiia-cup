# 参战角色与阵营的展示边界

2026-09-25，核查应用 main `072a324` 及本地 transcript 改动，提交前已对齐 main `9e500c9` 的新版 identity 页面。

## 规则与当前实现

- `side`（a/b）是计分、配对、门槛和汇总统计的阵营键；`role` 是某个版本或对局实际绑定的人物。两者不得混用。
- `v2/web/src/lib/role-identity.ts` 是具体参战者名称的共用解析入口。后端 role 快照优先，旧接口回退到已选版本的 options.role；战报兼容旧记录时，使用本局实际出现的角色 speaker。角色必须属于对应阵营。
- `ScenarioModule.roles` 保存角色名和历史 ID 别名；不在各页面复制本能寺特例。不能因为 speakerLabels 声明了全部四个角色就认定四人均已参战。
- 未知、角色冲突或缺少绑定信息时明确显示「角色待确认」。不随机选一人，不从提示词猜人物，不将「主张杀信长」当成人物。
- 阵营选择、创建入口、门槛以及场景的按侧统计继续显示阵营；没有已选人物时，这些界面本来就不指某个具体参战角色。

## 平台核查

| 界面 | 原问题 | 本次处理／数据边界 |
| --- | --- | --- |
| 战报页头、参战卡、胜负徽标、结果卡、比分 | a/b 阵营标签优先于实际发言角色 | 全部由同一份本局角色上下文解析 |
| 对话／事件、隐藏目标、问询、结构化计分、计分合计 | speakerName 与账目各有一套解析规则 | 对 a/b 使用共用角色解析；保留裁判原文与分值，不替换自然语言里的立场描述 |
| 倾向轨迹图、回放、实况 | 图例复用错误 sideName；旧脚本角色 ID 无法归侧 | 支持角色别名，实况包含已到达的流式 speaker |
| 历史双场约战链接 | 当前场的两个人物被复用于另一场 | 不借用另一场身份；直接读取该场 participants.role，旧接口缺少绑定时显示待确认 |
| 历史列表、对战条 | 从 catalog.sideAName/sideBName 制作“角色”映射 | 共用 outcome 入口读取各自 summary 的角色；旧服务器缺少字段时显示待确认 |
| 主人智能体主页、版本参赛按钮 | 场景阵营名充当人物；按钮可能借用另一版本角色 | 优先使用对应版本 role，旧接口兼容 options |
| 构建器、约战中的己方出战版本 | 使用场景阵营名 | 根据当前选角／实际出战版本解析 |
| NPC 主页 | 预设选角存在，却只显示 sideName | 读取本场 NPC profile 的 role，保留 match 上下文；不借用当前预设推断历史人物 |
| 公开智能体、兄弟智能体、归档、按 ID 查询的对方版本 | 接口只有阵营／版本 ID，缺少人物绑定 | 已接入各自版本／latestVersionID 对应的 role，不继承当前智能体的角色 |
| 场景目录、阵营介绍、我的智能体的分组、创建入口、门槛、按侧胜率 | 展示的就是阵营聚合 | 保持阵营语义，不随某一局的人物替换 |
| 首页对话节选、通知、锦标赛、智能体历史胜负 | 展示已有发言人、玩家身份或相对胜负，没有用场景阵营替代具体角色的前端路径 | 保持现有语义 |

## 后端契约与交付边界

2026-09-25，后端在独立 worktree `axiia-cup-v2-role-identity` 实现，已合并 [后端 PR #71](https://github.com/paideia-ai/axiia-cup-v2/pull/71)。前端接入随本轮战报改动交付；PR 与本地预览均不代表已部署。

- 版本保存、列表、diff、公开版本、版本查询、预设、NPC、对手清单、智能体清单及归档提供可选 `role: { key, name, side }`。公开接口只投影身份，不公开玩家 prompt 或整个 options。
- 对局已在 dispatch 保存脚本 SHA、参数 JSON，绑定版本不可变；使用这份开局配置恢复双方角色，不重复建角色数据库列。detail、历史列表、智能体／NPC 历史共用投影，不用最新版本或更新后的 NPC 预设推断旧对局。
- `MyAgentDTO.role` 对应 `latestVersionID`；对手列表对应实际参赛版本（无标记时为最新版本）。所查看的公开版本分别带自己的 role。
- 旧角色 ID 通过历史脚本标签及 lane 归属解析；实际发言人可恢复缺失绑定，只接受每侧唯一角色。原始数据不足或矛盾时才保留待确认，不猜人物。
- 前端 roleIdentity 优先采用后端绑定名，并验证 side；无新字段的旧服务器继续走本局 speaker／版本 options 兼容路径。列表无需另取完整 transcript。

## 验证范围

角色解析测试覆盖本能寺四种对阵组合、三种旧 ID 别名、跨阵营错误选角、角色冲突、空或损坏 options、未发言、普通固定角色场景、结构化和旧散文计分。
页面测试覆盖本能寺真实历史快照、角色不同的历史版本卡片、历史版本链接及本场 NPC 身份；既有战报、构建器、智能体、场景页与归档测试继续回归。所有预览均为本地数据，不代表线上部署或共享人测通过。
