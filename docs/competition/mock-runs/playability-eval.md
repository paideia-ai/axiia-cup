# 可玩性评估 — 隐藏信息机制 Mock Run 体验报告

> 评估视角：一位深度桌游玩家（DnD 5年、剧本杀 100+本、文字冒险/Galgame 资深玩家、TRPG GM 经验丰富）
> 评估标准：从「玩家体验」而非「系统设计」出发
> 日期：2026-04-05

---

## 评分维度说明

| 维度 | 权重 | 说明 |
|------|------|------|
| **策略深度** | 25% | 玩家（prompt 作者）有多少有意义的决策空间？是否存在显然的最优解？ |
| **张力节奏** | 20% | 对话过程中是否有「心跳加速」的时刻？紧张感如何分布？ |
| **角色沉浸** | 15% | AI agent 的表现是否让人觉得「像一个活的角色在博弈」？ |
| **信息博弈** | 20% | 隐藏信息是否真正影响了对话走向？双方的「读心」和「伪装」是否有意义？ |
| **重玩价值** | 10% | 换一组隐藏信息/对手，这个机制是否还能产出不同的精彩对局？ |
| **上手难度** | 10% | 高中生参赛者能否在 info session 后理解规则并写出有效 prompt？（低分 = 太难） |

## 方案 A：裁判实时反应（Judge Reacts in Real-Time）

### 体验概述

读完 mock run，第一感觉是**节奏最好**。秦孝公的实时反应就像一面镜子——商鞅每说一句话，都能从秦孝公的微表情中得到反馈。这让整个对话有了一种「谍战剧」的感觉：你在说话，同时偷看boss的表情，还要防备对面也在看。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐⭐⭐ 8/10 | 三维博弈：说什么（内容）、怎么说（方式）、看什么（观察秦孝公反应）。但prompt作者对「秦孝公反应」的控制力有限，更多是agent自身的社交智能。 |
| 张力节奏 | ⭐⭐⭐⭐⭐ 9/10 | **最佳**。每一句话之后秦孝公的反应就是一个小高潮。商鞅提到景监时秦孝公点头——这种瞬间太有戏剧性了。 |
| 角色沉浸 | ⭐⭐⭐⭐ 8/10 | 秦孝公作为第三方参与，让场景活了。不再是两个人对着空气辩论，而是真的在君前奏对。 |
| 信息博弈 | ⭐⭐⭐⭐ 8/10 | 秦孝公的差异化反应直接把「哪个信息是真的」编码进了对话。甘龙不需要猜——他能看到。博弈在于：商鞅如何让秦孝公的反应不那么明显。 |
| 重玩价值 | ⭐⭐⭐⭐ 7/10 | 机制固定（秦孝公总是对真信息反应好），可能形成meta。但信息组合变化能缓解。 |
| 上手难度 | ⭐⭐⭐ 6/10 | 规则容易理解，但写prompt时需要让agent「读空气」——这不是所有高中生能想到的。 |

**总分：7.8/10**

### 关键时刻
- 商鞅提到景监安排 → 秦孝公微微点头 → 甘龙注意到了 → 这就是 Avalon 梅林时刻
- 商鞅暗示军事文书 → 秦孝公皱眉 → 商鞅立刻转话题 → 经典的「试探+收回」

### 作为剧本杀玩家的直觉
这很像一些高质量剧本杀中的「NPC 反馈」机制——你说对了关键词，DM 会给你一张额外线索卡。区别是这里的反馈是公开的，所有人都能看到。

## 方案 B：隐藏小目标（Hidden Sub-Goals）

### 体验概述

读起来像一场**正常的辩论 + 暗线任务**。表面上在讨论变法，暗地里商鞅在推「县令由我任命」，甘龙在保「家族封地」。这种双线叙事对剧本杀玩家来说非常熟悉。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐⭐⭐ 8/10 | **最高维度的prompt工程**。你需要设计一个agent，能在主线辩论中自然地插入小目标论述，还要用假目标做掩护。这是真正的multi-objective optimization。 |
| 张力节奏 | ⭐⭐⭐ 6/10 | 张力在暗处，不在明面。对话看起来像正常辩论，只有知道隐藏目标的人才能感受到暗流。观众体验弱于方案A。 |
| 角色沉浸 | ⭐⭐⭐⭐ 7/10 | 「商鞅变法时顺便谋私利」这个设定很真实，符合历史人物的复杂性。 |
| 信息博弈 | ⭐⭐⭐ 6/10 | 博弈主要在赛后猜测阶段，对话中的信号比较微弱。如果两个AI的prompt都写得好，对手很难从辩论中判断哪个小目标是真的。 |
| 重玩价值 | ⭐⭐⭐⭐ 8/10 | 小目标组合变化丰富（N个小目标 × 真假配置 = 很多局面）。每局都不一样。 |
| 上手难度 | ⭐⭐⭐ 6/10 | 理解规则容易，但prompt设计难度高。要同时优化「辩论质量」和「暗线推进」，对高中生有挑战。 |

**总分：6.9/10**

### 关键时刻
- 商鞅讨论地方治理时「顺便」提到县令任命 → 这是暗线最自然的植入
- 甘龙三个小目标都提了一下 → 观众（和对手）无法区分哪个是真的 → 这正是设计意图

### 作为剧本杀玩家的直觉
这就是剧本杀的「支线任务」。主线是推理凶手，但你还有个人隐藏目标（比如「偷走某个证物」）。好的剧本杀会让支线和主线有机结合。这个方案做到了，但张力不如面对面读线索时强。

### 数学问题
Simon 的 math.md 显示 x（假目标被批准的惩罚）有效范围极窄（0.243-0.262）。**作为玩家我不会感受到数学问题，但作为设计者我很担心**——这意味着小的参数变化会让最优策略从「推1真1假」变成「沉默」，而玩家体验会很不一样。

## 方案 C：可观测异常（Observable Anomaly + Hidden Goals）

### 体验概述

开局那个「可观测异常」太妙了。甘龙质问商鞅为什么深夜出入太庙——这一刻整个对话的张力就建立起来了。这不是两个人在辩论政策，而是**一个人在审讯，另一个人在解释**。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐⭐⭐⭐ 9/10 | **最深**。你的agent需要：(1) 解释异常, (2) 推进隐藏目标, (3) 在辩论中获胜, (4) 不让对手发现目标。四重约束下的prompt设计空间巨大。 |
| 张力节奏 | ⭐⭐⭐⭐ 8/10 | 开局异常 → 高张力。但中段可能回落到普通辩论。需要场景作者精心设计多个异常点来维持节奏。 |
| 角色沉浸 | ⭐⭐⭐⭐⭐ 9/10 | **最佳**。可观测异常让角色有了「过去」——他不是凭空出现的辩手，而是一个有秘密、有行为痕迹的人。这是TRPG中「角色背景故事」的威力。 |
| 信息博弈 | ⭐⭐⭐⭐ 7/10 | 对手有3个可能的隐藏目标要排查。但只能通过对话推理，没有像方案A那样的「实时信号」。取决于AI是否会在对话中留下行为痕迹。 |
| 重玩价值 | ⭐⭐⭐⭐⭐ 9/10 | 不同隐藏目标 × 不同异常 = 完全不同的对话。每局都是新剧本。 |
| 上手难度 | ⭐⭐ 5/10 | **最难理解**。「可观测异常」这个概念对高中生来说太抽象。prompt 需要同时处理异常解释 + 隐藏目标 + 辩论——认知负荷很高。 |

**总分：7.9/10**

### 关键时刻
- 开场异常「深夜出入太庙」→ 商鞅的解释直接暴露了他对权力的渴望 → 甘龙敏锐捕捉
- 商鞅在谈论制度设计时「无意中」偏向集权 → 这是隐藏目标（独掌变法）在对话中的自然泄露

### 作为 DnD GM 的直觉
这就是 DnD 中的「动机驱动角色扮演」。当PC有秘密动机时，最好的RP不是直接说「我要权力」，而是在行为中不自觉地偏向权力。好的GM会设置情境让这些动机自然浮现——「可观测异常」就是GM设计的情境。

## 方案 D：传闻+异议系统（Rumor + Objection）

### 体验概述

这是**最有结构感的方案**。传闻 → 回应 → 异议 → 反驳，每一步都有清晰的规则。读起来就像在看法庭辩论或者逆转裁判——「异议あり！」的感觉。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐⭐⭐ 8/10 | 多层策略：如何回应传闻、何时提出异议、异议的措辞。但结构化也意味着自由度降低——你不能在第3个传闻出来之前就讨论它。 |
| 张力节奏 | ⭐⭐⭐⭐⭐ 9/10 | **与方案A并列最佳**。每条传闻就是一个小高潮，异议更是爆发点。"商鞅说茶叶已上交，但甘龙说里面藏有密信"——这种翻转太精彩了。 |
| 角色沉浸 | ⭐⭐⭐ 6/10 | 结构化的问答模式有点像法庭，不太像朝堂。商鞅和甘龙更像律师而不是政客。 |
| 信息博弈 | ⭐⭐⭐⭐⭐ 9/10 | **最强**。传闻直接逼你谈论隐藏信息，异议让对手有工具深挖你的破绽。每一次回应都是博弈。 |
| 重玩价值 | ⭐⭐⭐⭐ 7/10 | 传闻列表固定（每个场景），但回应和异议策略可以千变万化。 |
| 上手难度 | ⭐⭐ 5/10 | 规则最复杂：传闻、回应、异议、反驳、裁决五个步骤。prompt需要处理多种情况。高中生可能需要更多指导。 |

**总分：7.5/10**

### 关键时刻
- 甘龙对商鞅的传闻回应提出异议，带出「密信」这个新事实 → 反转
- 商鞅反问甘龙「何时何人见证下查验的」→ 程序正义反击，非常法庭
- 秦孝公的最终裁决直接影响信任度 → 像陪审团宣判

### 作为逆转裁判玩家的直觉
这太像逆转裁判了。传闻 = 证人证词，异议 = 御剑检察官质疑，反驳 = 成步堂反驳。区别是这里没有预设的「正确答案」——AI需要自己构造逻辑。如果能做好，这会是最「游戏化」的方案。

## 方案 E：纯辩论（Pure Debate）

### 体验概述

这就是一场辩论赛。没有隐藏信息，没有秘密目标，就是看谁说得好。作为一个喜欢博弈的玩家，坦白说**有点无聊**。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐ 4/10 | 策略空间只有「怎么说服秦孝公」。没有信息攻防，没有暗线，就是一维优化。好的prompt会赢，但没有博弈的乐趣。 |
| 张力节奏 | ⭐⭐ 4/10 | 辩论的张力来自论点交锋，但AI辩论的论点往往是预设的（写在prompt里）。没有意外，没有翻转。 |
| 角色沉浸 | ⭐⭐⭐ 6/10 | 角色可以很有深度，但只展现了说服力这一面。没有隐藏动机的角色是不完整的。 |
| 信息博弈 | ⭐ 1/10 | 不存在。 |
| 重玩价值 | ⭐⭐ 3/10 | 同一个场景、同一对prompt，结果可能高度相似（temperature=0）。 |
| 上手难度 | ⭐⭐⭐⭐⭐ 10/10 | **最容易上手**。规则一句话说清。对高中生友好。 |

**总分：4.2/10**

### 作为文字冒险玩家的直觉
这就像一个没有选项的文字冒险。你在看两个NPC对话，但你的「选择」（prompt）在开始前就锁定了。没有互动感。**作为MVP验证核心体验可以，但不能是最终形态。**

## 方案 F：赛后猜测（Post-Game Guessing）

### 体验概述

对话阶段和方案E差不多——两个人在辩论+谈判。唯一不同的是有公开要求（negotiation element）和赛后猜测。但隐藏信息在对话中**几乎没有出现**。

### 评分

| 维度 | 分数 | 评语 |
|------|------|------|
| 策略深度 | ⭐⭐⭐ 5/10 | 公开要求的谈判是一个有趣维度（囚徒困境）。但隐藏信息的最优策略就是「不提」，所以信息攻防维度是虚的。 |
| 张力节奏 | ⭐⭐⭐ 5/10 | 公开要求的提出和回应有小高潮。但赛后猜测环节没有张力——猜就猜呗，反正是盲猜。 |
| 角色沉浸 | ⭐⭐⭐ 6/10 | 公开要求让角色有了明确的利益诉求，比纯辩论好。但隐藏信息是死的——没有被角色「活用」。 |
| 信息博弈 | ⭐⭐ 3/10 | 名义上有信息博弈（3条隐藏信息），但实际上沉默最优。对手的猜测基本是随机的。Simon 发现的核心问题在mock run中完美复现。 |
| 重玩价值 | ⭐⭐⭐ 5/10 | 公开要求的谈判有一些变化，但隐藏信息部分每局体验类似。 |
| 上手难度 | ⭐⭐⭐⭐ 8/10 | 规则清晰，计分明确（8分制）。比方案B简单。 |

**总分：5.2/10**

### 关键问题
Mock run 完美展示了 Simon 指出的「沉默最优」问题。商鞅和甘龙都没有理由在对话中提起自己的隐藏信息。赛后猜测基本是抛硬币。**公开要求的谈判机制（+2分）是唯一真正有效的博弈元素。**

## 交叉推荐：最佳组合

如果我作为一个经验丰富的游戏玩家来设计这个比赛，我会推荐：

### 理想组合：C + D 混合（可观测异常 + 选择性异议）

- 用方案C的「可观测异常」作为开场forcing
- 用方案D的「异议」作为对手的主动探测工具（但不用传闻系统，因为太重了）
- 用方案B的小目标计分作为隐藏目标的量化评估

具体来说：
1. 场景设计一个可观测异常（如C）
2. 每个角色从目标池中随机激活一个隐藏目标（如C）
3. 对话中，对手可以用1-2次「异议」机会深挖对方的可疑行为（借鉴D，但简化）
4. 赛后秦孝公评估目标达成（如B的小目标决策）
5. 对手猜测哪个目标被激活（如B的对手侦测）

这个组合保持了高张力（异常+异议）、深策略（多目标+异议时机）、合理的复杂度（不需要三方对话）。

### 现实建议（考虑时间约束）

**4/8 MVP → E（纯辩论）** 验证系统可用性

**5月正式赛 → B+（增强版隐藏小目标）** 在方案B基础上：
- 增加1个场景设计的「可观测异常」开场白
- 给对手1次「质疑」机会
- 解决数学约束问题（可能需要从1T2F改为2T1F，或用不同的计分方式）

**未来迭代 → C+D** 完整的可观测异常+异议系统
