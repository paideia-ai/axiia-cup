# 单场 PvP 约战（2026-09-17）

一次约战只生成一场。玩家从商鞅智能体点击出战，就使用该商鞅版本挑战对方甘龙；从甘龙进入，则使用该甘龙版本挑战对方商鞅。系统不再自动交换角色，也不要求本次提交双侧阵容。

出战版本沿用当前页面规则：点击版本卡时使用该版本，否则取当前智能体的参赛版本，再回落到最新版。按玩家约战时，对方使用对侧的参赛版本或最新版；按版本 ID 约战时，必须指定本场景的对侧版本，并保留该版本。

发起人支付这一场的积分，只能领取自己获胜时的返还。被约方不付费、不领奖，无需确认。报价、连续相同角色加价、并发占用和失败退款都按一场处理。PvE 双侧解锁门槛与每日同一对手约战上限保持不变。

`POST /v1/challenges` 的 `mine` 只允许一个侧别，例如 `{ "a": { "versionID": 123 } }`。返回的 `matchIDs` 只有一个元素；新记录的 `challengeLeg` 为空。历史双场记录仍可查看，不修改旧账目。

此次修改涉及 `axiia-cup/v2/web` 与 `axiia-cup-v2` 的约战创建、积分报价和通知。两个版本需协调发布：旧前端提交双侧阵容会被新后端拒绝，新前端的单侧请求也会被旧后端拒绝，均不创建对战或扣款。

本决定取代旧版 #66 的双场创建和双侧阵容要求。旧验收材料里与这两项相冲突的预期不再适用；历史双场展示的预期仍适用。
