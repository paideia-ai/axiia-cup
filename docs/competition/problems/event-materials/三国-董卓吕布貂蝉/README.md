# 董卓、吕布、貂蝉事件原始材料

本目录为“三国历史题”保存可追溯的原始文本。材料分为两层：

- `正史/`：陈寿《三国志》以及二十四史中的另一部直接史源《后汉书》。
- `文学/`：罗贯中《三国演义》中构成“董卓—吕布—貂蝉”故事的核心回目。

所有文件均于 **2026-07-24** 从中文维基文库下载，并固定到具体修订版本。正文保留繁体字和来源校注，不做现代化改写。

## 史料边界

1. **貂蝉是《三国演义》中的具名人物，不是现存正史中的具名人物。**《三国志·吕布传》只说吕布“与卓侍婢私通”，《后汉书·吕布传》对应文字为“私与傅婢情通”；两书都没有写出该女子姓名，也没有正史中的“王允献貂蝉、连环计”。
2. 正史确认的主线是：董卓诱使吕布杀丁原；董卓与吕布誓为父子；董卓掷手戟、吕布与董卓婢女私通，使吕布不安；王允、士孙瑞谋诛董卓并拉拢吕布；吕布最终参与杀董卓。
3. 《三国演义》第八、九回把正史里的“侍婢／傅婢”和王允谋诛董卓两条线，发展成貂蝉主动参与的连环计叙事。第三回则补足董卓与吕布关系的文学起点。
4. 《三国志》和《后汉书》本身都属于二十四史。本目录另取《后汉书》的董卓传、吕布传，并补入王允传中对谋诛董卓的独立叙述。二十四史其他卷中以后世比附、典故形式出现的零散“董卓”“吕布”不在本次收录范围内。
