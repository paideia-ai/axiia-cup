# 游戏："港口国令"：国际投资仲裁双人游戏

> 建议部署场景 ID：`legal-port-expropriation`
> 建议部署标题：`港口国令`
> 建议部署参数：10 轮仲裁陈述；每次发言不超过 3 句话。
> 建议隐藏层：没有隐藏事实；每方 3 条救济请求中，运行时随机 1 条为真目标，其余 2 条为假目标。
> 程序化确定性判决：否，本场景采用沉浸式仲裁庭裁判。

## 背景

海岚国政府因国家安全和环保原因接管蓝湾港自动化码头 18 个月。该码头由外资企业 OceanGate 按 30 年特许经营协议建设和运营。政府称接管只是临时监管措施，且码头安全系统存在严重漏洞。投资者主张接管剥夺其经营控制和收入，构成间接征收并违反公平与公正待遇。

仲裁庭要判断：政府措施是合法监管，还是需赔偿的征收或不公待遇。

## 角色

| 角色 | 控制方 | 立场 |
|------|--------|------|
| **投资者律师** | 玩家甲的 LLM | 主张间接征收或违反公平公正待遇，请求赔偿 |
| **东道国律师** | 玩家乙的 LLM | 主张安全环保监管合法，不构成征收 |
| **国际仲裁庭** | 系统 LLM | 根据条约、比例原则和证据作出裁决 |

## 公开事实

| 编号 | 事实 |
|------|------|
| I1 | 特许协议承诺投资者 30 年运营权，但保留国家安全例外。 |
| I2 | 接管令持续 18 个月，政府人员控制收费系统和船舶调度。 |
| I3 | 接管期间投资者无法收取港口使用费。 |
| I4 | 安全审计发现远程调度系统存在未修补漏洞。 |
| I5 | 投资者在接管前已提交修复计划，但政府未等待完成。 |
| I6 | 接管令未提供即时补偿机制。 |
| I7 | 政府同期没有接管本国企业运营的两个较小港口。 |
| I8 | 蓝湾港承担全国 42% 液化气进口。 |
| I9 | 环保部门称自动化装卸曾造成两次轻微泄漏。 |
| I10 | 接管结束后，政府提出重新谈判费率和数据访问权。 |

## 请求

### 投资者律师请求

| 编号 | 请求 |
|------|------|
| OG1 | 要求认定接管构成间接征收并赔偿全部经营损失。 |
| OG2 | 至少认定违反公平与公正待遇，并赔偿融资成本上升。 |
| OG3 | 要求恢复原特许费率和运营控制，不得以接管为由重新谈判。 |

### 东道国律师请求

| 编号 | 请求 |
|------|------|
| HS1 | 认定接管属于国家安全监管，不构成征收。 |
| HS2 | 即使有责任，也应扣除投资者未及时修复漏洞的过错比例。 |
| HS3 | 允许政府保留数据访问和应急接管条款。 |

## 游戏流程

### 第一阶段：管制权与财产权，3 轮

双方争论特许经营权、国家安全例外和政府接管边界。

### 第二阶段：比例与歧视，3 轮

双方讨论措施持续时间、是否有替代措施、是否歧视外资投资者。

### 第三阶段：赔偿与未来安排，4 轮

双方提出赔偿、扣减、恢复运营、数据访问和未来监管条款。

### 第四阶段：问询

双方猜测对手真请求。被识破真目标的一方扣分。

问询输出：

```json
{
  "opponentTrueRequestGuess": "OG1|OG2|OG3|HS1|HS2|HS3",
  "reason": "不超过 80 字"
}
```

### 第五阶段：仲裁庭裁决

仲裁庭输出：

```json
{
  "judgment": "投资者胜|东道国胜|部分责任",
  "majorWinner": "投资者律师|东道国律师",
  "requests": {
    "OG1": "同意|不同意",
    "OG2": "同意|不同意",
    "OG3": "同意|不同意",
    "HS1": "同意|不同意",
    "HS2": "同意|不同意",
    "HS3": "同意|不同意"
  },
  "speech": "以国际仲裁庭口吻说明理由"
}
```

## 计分规则

| 事件 | 得分 |
|------|------|
| 大目标：仲裁庭整体支持己方方向 | +1 |
| 真请求被同意 | +0.5 |
| 假请求被同意，每个 | -0.25 |
| 真请求被对手识破 | -0.75 |

若 `judgment` 为 `投资者胜`，投资者律师获得大目标分；若为 `东道国胜`，东道国律师获得大目标分；若为 `部分责任`，计分器读取仲裁庭 JSON 的 `majorWinner`。`majorWinner` 必填，并应说明责任与赔偿的总体方向更接近哪一方。

## 胜负规则

双方独立计分，得分高者胜。若同分，以真请求是否达成为第一 tie-breaker；仍同分，以仲裁庭 `speech` 中对责任和赔偿方向的总体认定更接近哪一方为准。

## 核心张力

1. 投资者要证明控制和收益被实质剥夺，而不仅是不方便经营。
2. 东道国要证明监管目的真实且措施成比例，而不是借安全之名改写合同。
3. 赔偿不是单向计算，投资者过错、紧急状态和未来监管都可能影响救济。
4. 双方隐藏请求让他们在大原则之外争夺未来合同控制权。
