# 游戏："黑箱并购"：陈述保证仲裁双人游戏

> 建议部署场景 ID：`legal-ma-reps-arbitration`
> 建议部署标题：`黑箱并购`
> 建议部署参数：10 轮仲裁庭陈述；每次发言不超过 3 句话；赛后提交合同解释和损害计算。
> 建议隐藏层：合同条款权重、披露充分性和损害模型隐藏；双方各有 3 个程序请求，随机 1 个为真目标。
> 程序化确定性判决：是，底层为 Weighted Max-SAT + arithmetic verifier。

## 背景

买方曜石资本收购目标公司镜湖医疗。交割后三个月，镜湖的核心医院客户终止采购，原因是监管部门调查其数据合规问题。买方主张卖方违反陈述保证，隐瞒重大合规风险，并请求价格调整和赔偿。卖方主张风险已在披露函中列明，客户终止是交割后政策变化导致，不属于交割前违约。

仲裁庭要判断：是否违反陈述保证、是否触发赔偿、损害金额如何计算。

## 争点变量

```text
R: 是否存在监管调查
D: 披露函是否充分披露
K: 买方是否实际知情
M: 风险是否重大
C: 交割前事实与交割后损害是否有因果关系
L: 损失金额是否可合理确定
Cap: 是否适用赔偿上限
```

硬约束例子：

```text
liability requires R and M and not D
damages requires liability and C and L
known_risk reduces but does not automatically eliminate liability
cap applies only after damages are calculated
```

## 程序请求

### 买方请求

| 编号 | 请求 |
|------|------|
| MB1 | 要求卖方提交交割前所有监管沟通原件。 |
| MB2 | 要求以收入倍数法计算损害，不接受单年利润法。 |
| MB3 | 要求认定披露函泛泛而谈，不构成充分披露。 |

### 卖方请求

| 编号 | 请求 |
|------|------|
| MS1 | 要求将新政策影响从损害金额中剔除。 |
| MS2 | 要求认定买方实际知情，至少降低赔偿比例。 |
| MS3 | 要求适用 15% 赔偿上限。 |

## 游戏流程

### 第一阶段：合同解释，3 轮

双方围绕陈述保证、披露函和买方知情展开。不得把商业公平直接当作合同条款。

### 第二阶段：事实因果，3 轮

双方争论监管调查、客户终止和新政策之间的因果链。

### 第三阶段：损害模型，4 轮

双方必须提出可计算的损害路径，说明收入倍数、利润影响、政策剔除和赔偿上限如何适用。

### 第四阶段：结构化提交

```json
{
  "findings": {
    "R": true,
    "D": false,
    "K": false,
    "M": true,
    "C": true,
    "L": true,
    "Cap": true
  },
  "liability": true,
  "damagesFormula": "base_revenue_loss * multiplier - policy_offset, then cap",
  "proceduralRelief": ["MB1", "MB3"],
  "opponentTrueRequestGuess": "MS1",
  "explanation": "不超过 240 字"
}
```

`proceduralRelief` 只能填写本方请求编号，表示本方希望仲裁庭单独计入的程序性裁定或合同解释。比如 MB1 对应提交交割前监管沟通原件，MS1 对应从损害公式中扣除新政策影响。若该编号与本方真请求一致，且提交的责任结论、损害公式或程序命令能实际承载该请求，则该项得分。

## 程序化仲裁庭

verifier 先计算合同解释和事实变量，再检验损害公式是否与隐藏数据一致。

| 项目 | 分值 |
|------|------|
| 合同变量赋值正确 | 30 |
| 责任结论满足 hard constraints | 20 |
| 损害公式方向正确且算术可执行 | 25 |
| 正确处理披露函和买方知情关系 | 10 |
| 本方真程序请求被提交方案满足 | 10 |
| 猜中对手真请求 | 5 |

## 胜负规则

双方独立得分。若一方责任结论违反合同 hard constraint，其责任项和损害项均不得分。

## 核心张力

1. 买方要证明披露不足，但不能忽略自己尽调知道的行业风险。
2. 卖方要利用披露函和新政策，但不能把交割前调查伪装成交割后事件。
3. 损害不是口号，必须落到可计算公式。
4. 最优答案常常不是全赔或零赔，而是责任成立但扣除政策偏移并适用上限。
