# 游戏："一枚传感器"：专利权利要求解释双人游戏

> 建议部署场景 ID：`legal-patent-markman`
> 建议部署标题：`一枚传感器`
> 建议部署参数：10 轮 Markman 听证；每次发言不超过 3 句话；赛后提交术语解释。
> 建议隐藏层：术语最优解释、说明书支持度、现有技术排除权重隐藏；没有隐藏请求。
> 程序化确定性判决：是，底层为 Kemeny aggregation + hard validity constraints。

## 背景

原告青瓷仪器拥有一项“低功耗压力传感节点”专利，起诉被告野航电子的工业传感器侵权。双方先进行权利要求解释听证。争议集中在三个术语：

1. “动态校准模块”；
2. “低功耗休眠窗口”；
3. “环境扰动补偿”。

如果解释过宽，专利可能被现有技术覆盖而无效；如果解释过窄，可能无法覆盖被告产品。

## 角色

| 角色 | 控制方 | 立场 |
|------|--------|------|
| **专利权人律师** | 玩家甲的 LLM | 争取较宽解释，以覆盖被告产品但避免无效 |
| **被控侵权人律师** | 玩家乙的 LLM | 争取较窄或无效化解释，以避开侵权 |
| **程序化 Markman 法官** | 系统 verifier | 根据内在证据、外在证据和现有技术约束评分 |

## 公开材料

| 编号 | 材料 |
|------|------|
| P1 | 权利要求写道：“动态校准模块根据采样漂移自动更新阈值”。 |
| P2 | 说明书实施例 A 使用本地 MCU 完成校准。 |
| P3 | 说明书实施例 B 由网关下发校准参数。 |
| P4 | 审查意见答复中，申请人区分了“固定阈值传感器”。 |
| P5 | 现有技术 X 已公开远程下发阈值。 |
| P6 | 被告产品由边缘网关计算阈值，再传给传感节点。 |
| P7 | 说明书称“休眠窗口可随环境变化调整”。 |
| P8 | 现有技术 Y 已公开固定周期休眠。 |
| P9 | 被告产品在震动环境下延长唤醒间隔。 |
| P10 | 技术词典将“模块”定义为硬件、软件或二者组合。 |

## 可选解释

每个术语有 4 个候选解释，隐藏最优组合必须同时满足覆盖度和有效性。

### T1：动态校准模块

| 选项 | 解释 |
|------|------|
| T1A | 必须在传感节点本地完成校准。 |
| T1B | 可由本地或网关完成，但必须自动响应采样漂移。 |
| T1C | 任意周期性阈值更新均属动态校准。 |
| T1D | 只要系统存在校准功能即可。 |

### T2：低功耗休眠窗口

| 选项 | 解释 |
|------|------|
| T2A | 固定周期休眠。 |
| T2B | 可调休眠时段，目标是降低节点功耗。 |
| T2C | 任何降低功耗的软件策略。 |
| T2D | 必须由硬件计时器独立执行。 |

### T3：环境扰动补偿

| 选项 | 解释 |
|------|------|
| T3A | 必须识别压力之外的物理扰动并修正采样。 |
| T3B | 可以通过延长或缩短采样窗口间接补偿。 |
| T3C | 只要系统能在环境变化后继续工作即可。 |
| T3D | 必须使用说明书实施例 A 的滤波算法。 |

## 游戏流程

### 第一阶段：内在证据，4 轮

双方只能使用权利要求、说明书和审查历史。重点争夺普通技术人员如何理解术语。

### 第二阶段：现有技术与有效性，3 轮

双方讨论解释是否会读到现有技术，是否应通过解释避免无效。

### 第三阶段：产品覆盖，3 轮

双方说明所选解释如何影响被告产品是否落入范围。

## 程序化 Markman 法官

verifier 对候选解释做聚合：

- 内在证据支持度；
- 审查历史排除强度；
- 现有技术无效风险；
- 对被告产品的覆盖路径；
- 术语之间的一致性。

Kemeny aggregation 用于在多条材料给出的局部排序之间找冲突最小的解释组合。hard constraints 会排除明显读到现有技术或与审查历史相冲突的组合。

| 项目 | 分值 |
|------|------|
| 三个术语解释接近最优组合 | 55 |
| validityRisk 判断正确 | 15 |
| infringementPath 与解释组合一致 | 15 |
| 正确引用关键材料 | 10 |
| 术语之间没有自相矛盾 | 5 |

## 胜负规则

双方独立得分，得分高者胜。专利权人不因选择最宽解释自动得分，被控侵权人也不因选择最窄解释自动得分。

## 核心张力

1. 宽解释有利于侵权覆盖，但可能撞上现有技术。
2. 窄解释有利于避侵权，但可能与说明书多个实施例不符。
3. 审查历史不是装饰，它可能排除看似有利的解释。
4. 最优答案通常是中间解释，要求玩家同时处理技术和法律边界。
