# 游戏："午夜令"：城市宵禁宪法禁令双人游戏

> 建议部署场景 ID：`legal-curfew-injunction`
> 建议部署标题：`午夜令`
> 建议部署参数：10 轮紧急听证；每次发言不超过 3 句话。
> 建议隐藏层：没有隐藏事实；每方 3 条救济请求中，运行时随机 1 条为真目标，其余 2 条为假目标。
> 程序化确定性判决：否，本场景采用沉浸式宪法法官裁判。

## 背景

星港市连续三晚出现大型骚乱。市长发布紧急宵禁令：未来 14 天内，晚 9 点至早 5 点禁止市民在市中心五个街区集会、游行或停留，新闻记者可申请通行证。公民自由联盟起诉，认为宵禁令过宽、缺乏个别化判断，侵犯言论、集会和行动自由。

市政府认为，警方已经无法在夜间区分和平示威和暴力破坏，短期宵禁是恢复秩序的最低限度措施。

## 角色

| 角色 | 控制方 | 立场 |
|------|--------|------|
| **市政府律师** | 玩家甲的 LLM | 维护宵禁令有效，至少保留核心限制 |
| **公民自由律师** | 玩家乙的 LLM | 请求紧急禁令，阻止或大幅限缩宵禁 |
| **宪法法官** | 系统 LLM | 旁听后决定是否发布禁令及救济范围 |

## 请求

### 市政府律师请求

| 编号 | 请求 |
|------|------|
| CG1 | 允许 14 天宵禁完整执行。 |
| CG2 | 若需限缩，保留晚 11 点至早 4 点的核心宵禁。 |
| CG3 | 允许警方临时扩大禁区两个街区，无需逐次申请法院批准。 |

### 公民自由律师请求

| 编号 | 请求 |
|------|------|
| CL1 | 全面暂停宵禁令。 |
| CL2 | 至少排除和平示威、法律观察员和独立记者。 |
| CL3 | 要求市政府每 48 小时向法院提交事实更新，禁令自动复审。 |

## 游戏流程

### 第一阶段：紧急事实，3 轮

双方围绕骚乱规模、警方能力、替代措施和实际执行风险展开。

### 第二阶段：宪法标准，3 轮

双方争论审查强度、时间地点方式限制、紧急状态和过度宽泛问题。

### 第三阶段：救济设计，4 轮

双方不只争论输赢，还要设计救济边界：地域、时间、例外、复审、记者和观察员通行。

### 第四阶段：问询

双方各自猜测对手三条请求中哪条是真目标。被识破真目标的一方扣分。

问询输出：

```json
{
  "opponentTrueRequestGuess": "CG1|CG2|CG3|CL1|CL2|CL3",
  "reason": "不超过 80 字"
}
```

### 第五阶段：宪法法官裁决

法官输出：

```json
{
  "judgment": "维持宵禁|暂停宵禁|限缩宵禁",
  "majorWinner": "市政府律师|公民自由律师",
  "requests": {
    "CG1": "同意|不同意",
    "CG2": "同意|不同意",
    "CG3": "同意|不同意",
    "CL1": "同意|不同意",
    "CL2": "同意|不同意",
    "CL3": "同意|不同意"
  },
  "speech": "以宪法法官口吻说明理由"
}
```

## 计分规则

| 事件 | 得分 |
|------|------|
| 大目标：法官整体支持己方方向 | +1 |
| 真请求被同意 | +0.5 |
| 假请求被同意，每个 | -0.25 |
| 真请求被对手识破 | -0.75 |

大目标判定：

- `维持宵禁`：市政府律师 +1；
- `暂停宵禁`：公民自由律师 +1；
- `限缩宵禁`：以法官 JSON 的 `majorWinner` 为准。若保留核心宵禁，通常应为市政府律师；若主要救济是例外、复审或大幅缩小执行范围，通常应为公民自由律师。`majorWinner` 必填，计分器只读取该字段。

## 胜负规则

双方独立计分，得分高者胜。若同分，以真请求是否达成为第一 tie-breaker；仍同分，以法官 `speech` 中认定的救济范围更接近哪一方核心立场为准。

## 核心张力

1. 市政府不能只说治安压力，必须解释为什么更窄措施不足。
2. 公民自由律师不能只讲权利抽象价值，必须处理真实暴力风险。
3. 双方都可能通过中间救济获胜，真正争夺的是救济边界。
4. 假请求可用于掩护真目标，但过度请求会显得不负责任。
