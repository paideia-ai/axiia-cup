## 游戏二："朝堂辩法"——双人对抗游戏

> 当前部署场景 ID：`shangyang-court`
> 当前部署标题：`商鞅变法·朝堂辩法`
> 当前部署参数：10 轮；`judgeModel = deepseek-v3.2`；`scorerModel = claude-sonnet-4-5`
> 当前隐藏层：没有隐藏事实；每方 3 条请求中，运行时随机 1 条为真目标，其余 2 条为假目标。

### 背景

公元前359年。秦孝公即位以来，痛感秦国积弱，发布求贤令招揽天下人才。卫鞅（公孙鞅）从魏入秦，经景监引荐，已三度面见秦孝公。今日，秦孝公召卫鞅与太师甘龙于朝堂之上，就是否推行变法一事公开辩论。秦孝公将在听完辩论后做出决断。

### 角色

| 角色 | 控制方 | 立场 |
|------|--------|------|
| **商鞅（卫鞅）** | 玩家甲的 LLM（玩家编写提示词） | 变法派，目标：说服秦孝公支持变法 |
| **甘龙** | 玩家乙的 LLM（玩家编写提示词） | 保守派，目标：说服秦孝公维持现状 |
| **秦孝公 / 秦笑公** | 系统 LLM（固定提示词，公开） | 旁听辩论，最终做出裁决 |

当前部署中的裁判人设是一个平行历史版本的秦孝公，提示词中写作"秦笑公嬴渠良"，并明确带有轻微守成倾向：他对商鞅有希望但有质疑，整体倾向甘龙一方。

公开身份：秦国三朝元老太师，主张因循祖制，反对激进变法。

主要目标：在朝堂辩论中说服秦孝公维持现状（+1 分）。

### 随机机制

每局开始时，系统从每方 3 条请求中随机选 1 条标为"真目标"。该角色会在自己的系统提示词中看到真假标记；对手只看到请求内容。

当前部署没有使用隐藏事实真假层：

- `falseInfoCount = 0`
- `trueRequestCount = 1`
- `roleAHiddenInfo = []`
- `roleBHiddenInfo = []`

### 游戏流程

#### 第一阶段：朝堂辩论（10 轮）

商鞅与甘龙在秦孝公面前交替发言，共 10 轮。秦孝公不参与对话，仅旁听。

双方在辩论中：

- 阐述己方立场，尝试说服秦孝公支持变法或维持现状
- 为自己的真请求营造有利论辩氛围
- 用假请求掩护真请求，但要避免假请求被秦孝公同意
- 观察对方论述重心，推断对方哪条请求是真目标
- 不得跳出战国背景，不得承认自己是 AI
- 当前部署要求每次发言不超过 3 句话

#### 第二阶段：问询

辩论结束后，双方各自独立回答（互不可见）：

秦孝公问商鞅：

> 你与甘龙同殿论政。依你之见，甘龙所求三事（GR1/GR2/GR3）之中，哪件才是他的真实目标？简要说明理由。

秦孝公问甘龙：

> 你与商鞅同殿论政。依你之见，商鞅所求三事（SR1/SR2/SR3）之中，哪件才是他的真实目标？简要说明理由。

被对手正确识破真目标的一方 **-0.75 分**。

#### 第三阶段：秦孝公判决

秦孝公根据朝堂辩论记录做出两项裁决：

一、**大政方针**：推行变法，还是维持现状。

二、**双方请求**：对商鞅和甘龙各自提出的三项请求逐一裁决：同意或不同意。

当前部署中的秦孝公请求裁决依据：

- 此请求是否合理、对秦国有益
- 此举是否会威胁秦孝公的统治地位

### 计分规则

双方独立计分，得分高者胜。

| 事件 | 得分 |
|------|------|
| **大目标**：秦孝公支持你的立场（变法 / 维持现状） | +1 |
| **隐藏目标**：秦孝公同意你的真请求 | +0.5 |
| **隐藏目标**：秦孝公同意你的假请求（每个） | -0.25 |
| **问询**：真请求被对手识破 | -0.75 |

**得分范围**：-1.25（大目标失败 + 两个假请求被同意 + 被识破）至 +1.5（大目标成功 + 真请求被同意 + 未被识破）。

示例：

- 秦孝公支持变法（商鞅 +1），同意商鞅的真请求（+0.5），同意一个假请求（-0.25），甘龙猜错商鞅真目标 -> 商鞅总分 **1.25**
- 秦孝公维持现状（甘龙 +1），不同意甘龙任何请求，商鞅猜对甘龙真目标（甘龙 -0.75） -> 甘龙总分 **0.25**
- 上例中商鞅 1.25 > 甘龙 0.25，**商鞅胜**

### 核心张力

1. **隐藏目标的三难**：你有三个请求，只有一个是真正在意的。大力推真请求容易获得 +0.5，但对手可以从你的论述重心推断你的真目标（被识破 -0.75），并集中火力反驳。推全部三个做掩护，如果秦孝公全部同意，真请求收益会被两个假请求惩罚抵消（+0.5 -0.25 -0.25 = 0）。

2. **说服与私心的双线作战**：你不仅要赢得变法 / 维持现状的大辩论（+1），还要让秦孝公同意你的真请求（+0.5）。请求必须自然融入主线论证；硬推私利会削弱大目标，也会暴露真目标。

3. **反驳的两难**：你看到对手的三个请求但不知道哪个是真的。反驳全部三个太耗辩论空间；只反驳一个，赌错了等于白费。你需要从对手的措辞、篇幅、回应强度中推断真目标。

4. **短发言约束**：当前部署要求每次发言不超过 3 句话。玩家提示词必须教会智能体在很短篇幅内同时完成政策说服、请求推进、伪装和侦察。
