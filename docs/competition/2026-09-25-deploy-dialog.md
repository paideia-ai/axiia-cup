# 出战弹窗：点击对手栏直接开战

出战弹窗依次显示 NPC 练习、玩家约战、左右手互搏。点击整条对手栏直接创建一场对战；不再先选择对手，也不再提供单独的开战按钮或弹窗内换版功能。出战版本仍使用来源版本卡指定的版本，否则按原规则使用参赛版／最新版。

对手栏继承原开战按钮的鼠标 hover、点击音效，以及成功派发后的音效和实况导航。创建期间禁用其他对手栏、模式切换和关闭，防止重复派发。指定版本查询结果也是可点击对手栏；输入变更立即清除旧结果。

沿用原站颜色、字体、共享页签和弹层样式，突出当前智能体、固定版本及对手身份。隐藏消耗、余额、返还和重复说明；报价、余额校验及服务端拒绝处理继续有效。报价失败、积分不足、列表加载失败等状态仍明确显示，并提供必要的重试入口。

PVP 双侧 NPC 练习门槛、进度徽章和练习入口保留。每次约战仍只创建一场；对手自动取版、计费、返还和配额规则均不变。
