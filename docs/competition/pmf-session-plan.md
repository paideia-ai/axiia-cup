# Axiia Cup 内测 PMF 验证计划

> 改编自 Nora Alpha Playbook v2 + PMF Objectives Playbook
> 状态：4 月 9 日说明会后启动
> 测试人数：15 人内测
> 核心假设：**选手编写策略 prompt 操控 AI 在人文场景中对抗，这个行为本身是否足够有吸引力，让人反复参与？**

---

## 与 Nora PMF 框架的关键差异

| 维度 | Nora（交易工具） | Axiia Cup（对抗赛） |
|------|-----------------|-------------------|
| 产品类型 | SaaS，持续推送 | 竞赛/游戏，回合制 |
| 核心行为 | 看到 alert → 改变交易决策 | 写 prompt → 测试 → 提交 → 看结果 → 迭代 |
| 激活时刻 | "AI 帮我发现了我自己发现不了的信号" | "我写的文字真的改变了 AI 的辩论表现" |
| 留存驱动力 | 工作流依赖（每天需要看） | 竞技循环（输了想赢，赢了想稳） |
| 有机拉力 | 分享截图到交易群 | 分享对战记录、邀请朋友来打 |

---

## PMF 验证层级（适配竞赛产品）

```
Layer 5: 商业化        "学校/机构会付费举办吗？"
Layer 4: 有机拉力      "选手会自发拉人来比赛吗？"
Layer 3: 留存          "选手会反复迭代 prompt 并持续参赛吗？"
Layer 2: 激活          "选手是否体验到'我的文字操控了 AI'的时刻？"
Layer 1: 场景吸引力    "商鞅变法这个场景是否让人想玩？"
```

**本次内测目标：验证 Layer 1-3。Layer 4-5 仅做观察记录，不主动推。**

---

## Layer 1: 场景吸引力

### 核心问题
*商鞅变法·朝堂暗战这个场景，是否让选手产生"我想试试"的冲动？*

### 信号：有效
- 选手看完场景描述后主动讨论策略思路
- 选手对角色卡内容有具体反应（"甘龙这个角色有意思"）
- 选手主动问"还有其他场景吗？"

### 信号：无效
- 选手看完场景描述后沉默或礼貌性点头
- 反馈是"挺有意思"但没有任何后续行动
- 选手对历史背景感到困惑或无感

### 度量
| 指标 | 目标 | 低于此值 = 报警 |
|------|------|----------------|
| 说明会后 24h 内注册率 | ≥ 80%（12/15） | < 60% = 场景或说明会未打动人 |
| 注册后 24h 内进入试炼场 | ≥ 60% | < 40% = 注册了但不想玩 |

---

## Layer 2: 激活

### 核心问题
*选手是否体验到"我写的 prompt 真的决定了 AI 的行为"这个时刻？*

这是 Axiia Cup 的"holy shit"时刻。不是"AI 好强"，是"**我的策略让 AI 变强了**"——主体是选手，不是 AI。

### 信号：激活发生了
- 选手能具体描述自己的策略思路（"我让商鞅先示弱再反击"）
- 选手对比了不同 prompt 版本的效果差异
- 选手主动尝试不同模型（"DeepSeek 在这个场景表现不一样"）
- 选手讨论中出现动词："试了""改了""发现了""对比了"

### 信号：激活没发生
- 选手随便写了一个 prompt 提交，没有测试过
- 选手说"我不知道怎么写"但没有在试炼场尝试
- 选手把 prompt 写成了直接的对话内容，而非策略指令
- 选手玩了一次就再也没打开过

### 度量
| 指标 | 目标 | 低于此值 = 报警 |
|------|------|----------------|
| 试炼场使用次数（人均） | ≥ 3 次 | < 2 次 = 没有探索行为 |
| 试炼场到提交的转化率 | ≥ 50% | < 30% = 试了但没觉得值得提交 |
| 提交前修改 prompt 次数（人均） | ≥ 2 次 | 0 次 = 没有迭代意识 |

---

## Layer 3: 留存（竞技循环）

### 核心问题
*看到第一场对战结果后，选手会不会回来改 prompt 再打？*

这是竞赛产品的生死指标。交易工具靠工作流依赖留存，竞赛产品靠**竞技循环**留存：输了 → 想赢 → 改策略 → 再打。如果这个循环不转，产品就是一次性玩具。

### 信号：循环在转
- 选手看到输的比赛后，主动修改 prompt 重新提交
- 选手在群里讨论对手的策略（"你那个甘龙怎么写的？"）
- 选手比较排行榜位置，表达不甘心
- 选手主动要求"什么时候开下一轮？"

### 信号：循环没转
- 选手提交一次后再也没登录
- 选手看到输了没有任何反应
- 排行榜发布后群里没有讨论
- 选手说"挺好玩的"但再也没打开

### 度量
| 指标 | 目标 | 低于此值 = 报警 |
|------|------|----------------|
| 首轮结果发布后 48h 内重新提交率 | ≥ 40% | < 20% = 竞技循环未启动 |
| 提交版本数（人均，整个内测期间） | ≥ 3 版 | = 1 版 = 一次性行为 |
| 内测结束时仍活跃用户比例 | ≥ 50% | < 30% = 严重流失 |
| Sean Ellis "非常失望"比例 | ≥ 30% | < 20% = 产品不必要 |

---

## Layer 4 & 5: 仅观察，不主动推

### 有机拉力（Layer 4）——记录但不激励
- 有没有人自发分享对战记录到朋友圈/群？
- 有没有人问"我朋友能不能也来玩？"
- 有没有人在非 Axiia 的群里提到这个比赛？
- **不要做**：不要发奖励拉人、不要搞转发抽奖。此阶段只看自然行为

### 商业化（Layer 5）——记录但不测试
- 有没有老师/教育机构主动问"能不能给我们班用？"
- 选手对"付费参赛"的自然反应是什么？
- **不要做**：不要问"你愿意花多少钱"。太早了

## 执行节奏

### Day 0（今天，4/9）——说明会 + 移除障碍

**唯一问题：选手能在 10 分钟内完成注册 → 写 prompt → 跑一局试炼场吗？**

- [ ] 说明会按 [info-session-gameplan.md](info-session-gameplan.md) 执行
- [ ] 确认平台可正常注册、试炼场可正常跑
- [ ] 未参会者 2h 内发跟进消息（2min 精华片段 + 平台链接 + deadline）
- [ ] 记录说明会上的自然反应（谁问了什么问题、谁看起来兴奋、谁没反应）

### Day 1-3——Layer 1 验证：场景吸引力

**唯一问题：他们注册了吗？进试炼场了吗？**

| 日期 | 动作 |
|------|------|
| Day 1 | 追踪注册人数 + 试炼场使用人数。未注册者私信跟进一次 |
| Day 2 | 试炼场使用 < 40% → 找 2-3 个人 1 对 1 聊，问：哪里卡住了？是不想玩还是不会玩？ |
| Day 3 | Layer 1 判定：≥ 60% 进了试炼场 = 通过，继续；< 40% = 场景或 onboarding 有问题，暂停修 |

### Day 4-7——Layer 2 验证：激活

**唯一问题：有没有人在试炼场里反复测试和修改 prompt？**

| 日期 | 动作 |
|------|------|
| Day 4 | 在群里分享一个精彩对战片段（不用多说，让内容自己说话） |
| Day 5 | 追踪：谁提交了？谁修改过？谁只跑了一次就走了？ |
| Day 6 | 找 3-5 个已提交的选手聊：你的策略思路是什么？你试了几个版本？哪个有效？ |
| Day 7 | Layer 2 判定：≥ 30% 的人有明确的"策略思路" = 激活在发生；没人能说清自己的策略 = prompt 写作门槛太高或场景不够激发策略思考 |

### Day 8-10——第一轮对战 + Layer 3 验证开始

**唯一问题：看到结果后，他们回来改 prompt 了吗？**

| 日期 | 动作 |
|------|------|
| Day 8 | 启动第一轮瑞士轮对战 |
| Day 9 | 发布结果 + 排行榜。在群里只发结果，不做任何引导（观察自然反应） |
| Day 10 | 追踪：48h 内有多少人重新提交了新版本 prompt？群里有没有讨论？ |

### Day 11-14——Layer 3 深度验证 + 决策

| 日期 | 动作 |
|------|------|
| Day 11-12 | 进行第二轮对战 |
| Day 13 | 对仍活跃的选手发 Sean Ellis 问卷（"如果 Axiia Cup 不再举办，你会多失望？"） |
| Day 14 | **决策会议** |

## Day 14 决策矩阵

| 决策 | 所需证据 |
|------|---------|
| **扩大到公开赛（5/1 上线）** | 试炼场使用率 ≥ 60%，≥ 3 人多次迭代 prompt，Sean Ellis "非常失望" ≥ 30%，有自发讨论 |
| **继续内测，延后公开赛** | 数据有正向趋势但不够强，需要再跑一轮对战验证循环 |
| **调整方向（换场景/改机制）** | 试炼场使用率 < 40%，0 人迭代 prompt，反馈是"不知道怎么玩"或"场景不感兴趣" |
| **诚实止损** | 所有指标为负 + 用户反馈指向品类本身无需求（"AI 对抗赛这个东西没意思"） |

## 流失诊断（Churn Forensics）

从 Nora 直接搬过来的实践，适配竞赛场景：

1. **发现流失要快**：注册后 48h 未进试炼场 / 试炼场后 72h 未提交 / 对战结果发布后 48h 未重新提交 → 视为流失信号
2. **个人触达**：不是群公告，是私信。由了解这个人的团队成员发
3. **只问一个问题**："如果有一件事改了你就会继续玩，是什么？"
4. **记录到共享文档**：所有流失原因集中记录。当 ≥ 30% 的流失者说同一件事，那就是最重要的产品 insight

## 两个持续运转的飞轮

### 飞轮 1：场景-策略循环（产品侧）

```
选手写 prompt → 对战产生精彩/无聊的对话 →
团队分析什么样的 prompt 产生好对话 →
优化场景设计（角色卡、裁判规则、约束条件）→
下一轮对话更有深度 → 选手更投入 → 重复
```

**转速目标**：每轮对战后都做一次场景微调。不是大改——是基于对战数据的小幅优化。

### 飞轮 2：学习-行动循环（运营侧）

```
观察选手行为 → 找到"选手做了什么 vs 我们希望他们做什么"的最大 gap →
做一个最小改动 → 度量 gap 是否缩小 → 重复
```

**转速目标**：每天一次。每天早上看昨天的数据，下午做一个响应动作。

## 不要做的事

| 禁忌 | 原因 |
|------|------|
| 在群里反复催人提交 | 催来的提交不是真实需求信号。如果要催，说明产品没吸引力 |
| 帮选手写 prompt | 你验证的是"选手能否自主产生策略"，不是"你的策略好不好" |
| 过早增加场景 | 一个场景都没跑通就加场景 = 用数量掩盖质量问题 |
| 做复杂的数据仪表盘 | 15 个人，用 Google Sheet 追踪足够。把时间花在和选手聊天上 |
| 在 Layer 1 没验证前就讨论赛制优化 | 场景不吸引人，赛制再好也没用 |
