# 隐藏目标机制的数学分析

## 1. Cost of Silence 基本模型

### 设定
- 大目标（变法/不变法）：胜者 +1
- 真隐藏小目标被秦孝公批准：+0.5
- 被对手猜中真隐藏目标：-1
- 假隐藏目标被秦孝公批准：-x（待定）
- 推一个目标后秦孝公批准概率：p

### 各策略期望得分（仅小目标维度）

| 策略 | 真目标收益 | 假目标成本 | 识别期望损失 | 总期望 |
|------|-----------|-----------|-------------|--------|
| 沉默（3个都不推） | ~0 | 0 | -1/3 ≈ -0.33 | **≈ -0.33** |
| 只推真目标 | +0.5p | 0 | -1 | **0.5p - 1** |
| 推真+1假 | +0.5p | -xp | -0.5 | **0.5p - xp - 0.5** |
| 推真+2假（全推） | +0.5p | -2xp | -1/3 | **0.5p - 2xp - 0.33** |

p = 0.7 时的数值：

| 策略 | 期望（x=0.25） | 期望（x=0.35） |
|------|---------------|---------------|
| 沉默 | -0.33 | -0.33 |
| 只推真 | -0.65 | -0.65 |
| 真+1假 | -0.325 | -0.395 |
| 全推 | -0.33 | -0.47 |

> Cost of silence 成立的额外条件（真+1假 > 沉默）：p(0.5 - x) > 1/6。
> p=0.7 时要求 x < 0.262，与下界 x > 0.243 联立后有效范围极窄（0.243 < x < 0.262）。

## 2. Dependent vs Independent 小目标的等价问题

### 变量定义

| 变量 | 含义 |
|------|------|
| p_a | 秦孝公批准某个小目标的概率（前提：该目标在辩论中被推过） |
| p_b | 大目标达成的概率（即玩家赢得变法/不变法判决的概率） |
| r_i | Independent 小目标达成时的奖励分数 |
| r_d | Dependent 小目标达成时的奖励分数 |

### 两类小目标

- **Independent**：不依赖大目标结果（如"甘龙保留土地裁断权"），大目标输了仍可达成
- **Dependent**：需要大目标达成才能实现（如"商鞅获变法独断权"），大目标输了自动失败

### 期望值对比

Independent 小目标：
```
E_i = p_a × r_i
```

Dependent 小目标（需要大目标赢 AND 秦孝公批准）：
```
E_d = p_b × p_a × r_d
```

### 等价条件

假设 p_b = 0.5（双方实力均等时的合理近似），令两者期望相等：
```
p_a × r_i = p_b × p_a × r_d
r_d = r_i / p_b = 0.5 / 0.5 = 1.0
```

即 dependent 小目标的奖励需要设为 **1.0** 才能与 independent 的 0.5 等价。

### 问题

1. **r_d = 1.0 意味着 dependent 小目标与大目标同等价值**，扭曲激励——持有 dependent 小目标的玩家对赢大目标的需求远高于对手（赢大目标同时解锁 +1.0 的小目标奖励）。
2. 大目标输了 → dependent 小目标自动失败 → 双重惩罚（来自运气而非技能）。
3. p_b = 0.5 只是近似，实际 p_b 因双方 prompt 质量而异，等价关系在非对称局面下偏移。

## 3. 被识破惩罚 c 的最优值推导

### 问题

当前设计中"被对方猜中真隐藏目标"的惩罚 c = 1，但这个数值从未被推导过。本节从博弈论角度分析 c 的合理取值。

### 3.1 四策略模型

玩家有 3 个请求（1 真 2 假），需要决定如何在辩论中"推"这些请求。

**关键假设**：
- p = 秦孝公批准某个被辩论中推过的请求的概率（≈ 0.7）
- 未被推的请求批准概率 ≈ 0（"若此人从未提及相关话题，你凭什么相信他的请求出于公心？"）
- x = 0.25（假请求被批准的惩罚，已定）
- 对手只能从被推的请求中有效区分真假；未推的请求对手缺乏信号

**对手猜测概率 q 的建模**：
- 对手从 3 个请求中选 1 个作为猜测
- 如果玩家推了 N 个请求且给了大致相同的权重，对手在推过的请求中等概率猜测
- 理性对手知道玩家有动力推真请求（+0.5p 的收益），因此会将注意力集中在被推的请求上

| 策略 | 请求净收益 | q（对手猜中概率） | 期望 E |
|------|-----------|------------------|--------|
| 沉默（不推） | 0 | 1/3（随机猜） | **−c/3** |
| 只推真 | +0.5p | 1（完全暴露） | **0.5p − c** |
| 真+1假 | 0.5p − 0.25p = 0.25p | 1/2（二选一） | **0.25p − c/2** |
| 全推 | 0.5p − 0.5p = 0 | 1/3（无信号） | **−c/3** |

**关键性质**：全推和沉默的期望值完全相同（−c/3）。

这不是巧合——当 x = 0.25 时，推 N 个请求的净请求收益为 0.5p − (N−1)·0.25p，推全部 3 个时恰好为零。x = 0.25 的设计优雅之处在于：均匀推全部请求等价于什么都不推，额外的假请求纯粹是掩护工具，不创造任何请求收益。

### 3.2 排除"不推真"策略

一个可能的高阶策略：故意不推真请求，只推假请求做反向伪装。

推 1 假（不推真）：E = 0 − 0.25p − c·q'

即使假设对手完全被骗（q' → 0），E = −0.25p = −0.175。

关键是：不推真请求放弃了 +0.5p 的潜在收益。这只在 c·Δq > 0.5p 时值得。

由于 Δq ≤ 1/3（从 1/3 降到 0 的极限），需要 c > 1.5p ≈ 1.05。这超出了有效范围（见下文），所以**在有效范围内，不推真请求是严格劣策略**。

### 3.3 有效范围推导

设计目标：**"真+1假"是最优简单策略**（最有趣的博弈状态——玩家需要在掩护和效率之间权衡）。

**约束 1：真+1假 > 沉默**（隐藏目标维度有意义）

```
0.25p − c/2 > −c/3
0.25p > c/6
c < 1.5p
```

**约束 2：真+1假 > 只推真**（鼓励伪装而非裸推）

```
0.25p − c/2 > 0.5p − c
c/2 > 0.25p
c > 0.5p
```

合并：**0.5p < c < 1.5p**

p = 0.7 时：**0.35 < c < 1.05**

### 3.4 边际分析：每多推一个假请求的边际成本与收益

| 升级路径 | q 变化 | 边际收益（降低被识破） | 边际成本（假请求惩罚） | 值得的条件 |
|---------|--------|---------------------|---------------------|-----------|
| 只推真 → 真+1假 | 1 → 1/2 | c·(1 − 1/2) = c/2 | 0.25p | c > 0.5p |
| 真+1假 → 全推 | 1/2 → 1/3 | c·(1/2 − 1/3) = c/6 | 0.25p | c > 1.5p |

结论：
- 当 c < 0.5p（≈ 0.35）：连第一个假请求都不值得推 → 只推真
- 当 0.5p < c < 1.5p（0.35 ~ 1.05）：推一个假请求值得，第二个不值得 → **真+1假最优**
- 当 c > 1.5p（> 1.05）：推两个假请求都值得 → 全推最优，博弈退化

### 3.5 策略张力最大化

真+1假相对于两个替代策略的优势：

- vs 沉默：Δ₁ = 0.25p − c/6
- vs 只推真：Δ₂ = c/2 − 0.25p

当 Δ₁ = Δ₂ 时，真+1假在两个方向上的优势相等，策略张力最大（maximin advantage）：

```
0.25p − c/6 = c/2 − 0.25p
0.5p = 2c/3
c* = 0.75p
```

p = 0.7 时：**c* ≈ 0.525**

此时 Δ₁ = Δ₂ = 0.0875（各方向 ~9% 的大目标值）。

### 3.6 参与激励分析（关键问题）

真+1假 vs 沉默的 margin 是**玩家参与请求博弈的激励强度**。如果 margin ≈ 0，玩家没有动力参与请求博弈，这个维度形同虚设。

Margin = Δ₁ = 0.25p − c/6

| c | Margin（p=0.7） | 解读 |
|---|----------------|------|
| 0.50 | 0.092 | 强激励，明显值得参与 |
| 0.525 | 0.0875 | 最大张力点 |
| 0.75 | 0.050 | 中等激励 |
| **1.00** | **0.008** | **几乎无激励，参与与沉默几乎无差** |
| 1.05 | 0.000 | 临界点，完全无差 |

**c = 1 的核心问题：参与激励仅 0.008，不到大目标值的 1%。**

### 3.7 对手猜测精度 q 的变异性

上面的分析假设真+1假时 q = 1/2。实际上 q 取决于双方 prompt 质量：

- 高质量 prompt（好的伪装）：q ≈ 0.35（对手难以区分）
- 平均 prompt：q ≈ 0.50（对手在二选一中随机）
- 低质量 prompt（伪装拙劣）：q ≈ 0.65（对手能读出差异）

对于一个 q 水平的玩家，真+1假优于沉默的条件：

```
0.25p − qc > −c/3
0.25p > c(q − 1/3)
q < 1/3 + 0.25p/c
```

即：只有 q 低于某个阈值 q_max 的玩家才会从参与中获益。

| c | q_max（p=0.7） | 受益玩家范围 |
|---|---------------|------------|
| 0.50 | 0.683 | 广泛：几乎所有人都值得参与 |
| 0.75 | 0.567 | 中等：多数人值得参与 |
| **1.00** | **0.508** | **狭窄：仅略好于随机的玩家获益** |
| 1.05 | 0.500 | 临界：仅超过 1/2 的玩家获益 |

c = 1 时，q_max = 0.508。这意味着只有 deception 水平优于 1/2 的玩家才值得参与——而 1/2 恰好是"推了两个、对手随机猜"的基线水平。**大多数平均水平的参赛者会发现参与请求博弈是不值得的。**

### 3.8 隐藏技巧的 skill 表达

另一方面，c 越高，好 prompt 和差 prompt 的分数差距越大：

一个好 prompt（q=0.35）和差 prompt（q=0.65）的期望分差：
```
Δ_skill = c·(0.65 − 0.35) = 0.3c
```

| c | Skill 表达 | 相对于大目标 |
|---|-----------|------------|
| 0.50 | 0.15 | 15% |
| 0.75 | 0.225 | 22.5% |
| 1.00 | 0.30 | 30% |

c 越高越奖励技巧。但如果参与激励太低（3.6 的分析），多数玩家根本不参与，skill 表达就变成了空中楼阁。

**存在一个 tradeoff：c 太低则 skill 无处表达，c 太高则多数人不参与。**

### 3.9 大目标决定性

赢了大辩论的玩家在最坏情况下（被识破 + 1 个假请求被批准）的总分：

```
最坏总分 = 1 − c − 0.25 = 0.75 − c
```

| c | 赢大辩论最坏总分 | 大辩论决定性 |
|---|----------------|------------|
| 0.50 | +0.25 | ✅ 总是决定性（赢辩论 → 保证正分） |
| 0.75 | 0 | ⚠️ 边界（极端情况下打平） |
| 1.00 | −0.25 | ❌ 赢辩论仍可能负分，被翻盘 |

### 3.10 得分范围

总分范围 = [−0.5 − c, +1.5]

| c | 范围 | 对称性 |
|---|------|--------|
| 0.50 | [−1.0, +1.5] | 略不对称 |
| 0.75 | [−1.25, +1.5] | 接近对称 |
| 1.00 | [−1.5, +1.5] | 完全对称 |

c = 1 唯一的数学优势是给出了完美对称的得分范围。

### 3.11 综合对比

| 属性 | c = 0.5 | c = 0.75 | c = 1.0 |
|------|---------|----------|---------|
| 在有效范围内 | ✅ | ✅ | ✅（边界附近） |
| 参与激励 | 0.092（强） | 0.050（中） | 0.008（几乎为零） |
| 受益玩家范围 q_max | 0.683（广） | 0.567（中） | 0.508（极窄） |
| Skill 表达 | 0.15（中） | 0.225（高） | 0.30（最高） |
| 大辩论决定性 | 总是 | 边界 | 可被翻盘 |
| 得分范围 | [−1, +1.5] | [−1.25, +1.5] | [−1.5, +1.5] |
| 距最大张力点 c*=0.525 | 近 | 偏远 | 远 |

### 3.12 结论

**推荐 c = 0.75**，理由：

1. **参与激励实质存在**（margin = 0.05），不像 c=1 时几乎为零
2. **多数参赛者受益**（q_max = 0.567，多数玩家推请求优于沉默）
3. **skill 表达充分**（0.225，占大目标值的 22.5%）
4. **大辩论基本决定性**（赢辩论最坏情况为 0，不会负分）
5. 位于有效范围 [0.35, 1.05] 的中段偏上

如果更看重参与广度和大辩论决定性，可取 c = 0.5（更安全）。
如果更看重得分对称性，可保留 c = 1（但需接受参与激励极弱的代价）。

**不推荐 c = 1 的核心原因**：margin = 0.008 意味着隐藏目标维度在数学上近乎无效。玩家沉默和积极参与的期望分差不到大目标的 1%，绝大多数参赛者理性上不应参与请求博弈。
