# 历史游戏人物卡实际样例

这份文件只收集真实历史游戏/官方资料里的实际人物呈现方式，不放原创仿写。长段官方文案不整段复制；下面保留短标签、字段名、人物名、机制名和结构摘要，并附来源链接，方便回到原页面看完整原文。

用途：给 Axiia Cup 的历史人物小传、角色卡、裁判角色说明、赛前材料找真实参照。

## 读这些例子的方式

历史游戏里的人物小传大致分几类：

- **短列传型**：一到三句，身份 + 功业 + 称号或命运节点。
- **机制标签型**：人物不是一段传记，而是一组能力、特性、名品、倾向。
- **开局困境型**：人物卡包含起始位置、关系网、初始选择、适合玩家类型。
- **领袖议程型**：短传 + 独特能力 + 属性 + AI 议程。
- **战役钩子型**：不是角色履历，而是“他/她能否完成某个历史任务”的剧情钩子。
- **王朝角色型**：角色以年龄、信仰、家族、难度、生活路线、继承压力呈现。
- **资料库型**：人物、地点、事件作为历史知识节点，服务沉浸而不是玩法数值。

## 《信长之野望 出阵》：短列传型

来源页面：`登場武将｜信長の野望 出陣`

真实格式特征：

- 页面按武将头像排列。
- 每人通常只有两三句。
- 常用结构是：身份句、成就句、称号句。
- 还同时列出声优与语音按钮。

实际例子索引：

| 人物 | 页面里的实际写法抓点 | 可观察结构 |
|------|----------------------|------------|
| 织田信长 | `尾張の戦国大名`、`天下布武` | 地域身份 + 政治口号 + 灭敌扩张 |
| 丰臣秀吉 | `戦国一の出世頭` | 一句称号先定人格：出世、才智、人望 |
| 伊达政宗 | `伊達家17代当主`、`独眼竜` | 家系身份 + 年少称霸 + 外号 |
| 明智光秀 | `織田家臣`、本能寺讨取信长 | 主从身份 + 才智教养 + 突然谋反 |
| 德川家康 | `江戸幕府の創始者` | 后世结果先行 + 桶狭间后自立 + 结盟/臣服/扩张 |
| 武田信玄 | `甲斐守護`、`甲斐の虎` | 官职/地域 + 军事风格 + 外号 |
| 上杉谦信 | `越後の戦国大名`、`越後の龍` | 地域身份 + 军旗意象 + 外号 |
| 毛利元就 | `安芸の戦国大名`、`稀代の謀将` | 地域身份 + 权谋扩张 + 评价词 |
| 北条氏康 | 后北条三代当主、关东大国 | 家系世代 + 强敌对抗 + 地域霸权 |

这个类型适合做：

- 角色选择页上的短人物说明。
- 公开材料里的“速读小传”。
- 不需要玩家理解完整史料，只需要立刻知道此人的历史坐标。

## 《三国志 14》：武将个性/名品型

来源页面：`三國志14:登場武将`、`三國志14:登場武将 能力・個性`

真实格式特征：

- 页面强调“登场武将接近 1000 名”。
- 武将不是只靠传记区分，而是靠能力、个性、名品、施政位置区分。
- `个性`会影响战斗、内政、登用、移动、俸禄、负面限制等。

实际人物/机制例子：

| 人物或项目 | 页面里的实际字段 | 类型 |
|------------|------------------|------|
| 刘备 | 固有个性 `脱兎` | 退却/机动相关个性 |
| 关羽 | 固有个性 `神将` | 范围内友军攻防强化 |
| 张飞 | 固有个性 `闘将` | 被多支敌军邻接时不受包围效果影响 |
| 曹操 | 施政主義 `覇道` | 君主战略路线 |
| 孙权 | 施政主義 `割拠` | 内政、人事倾向 |
| 刘备 | 施政主義 `王道` | 组织图较均衡 |
| `奸雄` | 自势力部队全能力上升 | 强力正面个性 |
| `飛将` | 无视部分 ZOC/包围效果 | 机动战个性 |
| `勇将` | 攻城上升 | 攻城个性 |
| `名声` | 地域担当官时扩大占领 | 内政/占领个性 |
| `猪突` | 部分命令不可选 | 负面或约束型个性 |
| `強欲` | 俸禄增加 | 成本型负面个性 |
| `悪名` | 占领范围扩大需要更多兵 | 扩张惩罚型个性 |
| 孟德新书 | 曹操著兵法书 | 名品 |
| 赤兔马 | 一日千里名马 | 名品 |
| 青龙偃月刀 | 关羽爱用大薙刀 | 名品 |

这个类型适合做：

- Axiia Cup 角色的“行动重点”和“隐藏短板”。
- 把人物小传压成几个可评分的行为倾向。
- 给裁判问题增加抓手，例如“你是否利用了此人的负面个性约束”。

## 《Total War: THREE KINGDOMS》：开局困境/玩家类型型

来源页面：`Three Kingdoms Warlords - Total War Academy`

真实格式特征：

- 每个可玩军阀有固定栏目：`Hero Class`、`Nickname`、`Who is he?`、`Playstyle`、`Guanxi`、`Starting Position`、`Initial Dilemma`、`What kind of player is ... for?`
- 它把人物写成“历史人物 + 起始地图 + 关系网 + 玩法偏好”。
- 特别重要的是 `Initial Dilemma`：给玩家一个历史路线/反事实路线的选择。

实际例子索引：

| 人物 | 实际标签/栏目 | 页面呈现的角色核心 |
|------|---------------|--------------------|
| 曹操 | `Hero Class: Commander`、`Nickname: Strategic Mastermind` | 外交操纵、代理战争、关系操作、长期布局 |
| 公孙瓒 | `Vanguard`、`The Ironfist General` | 军事化治理、北方边境、防御与骑兵 |
| 孔融 | `Strategist`、`The Master Scholar` | 知识、教育、贸易、较和平的高发展玩法 |
| 刘备 | `Commander`、`Virtuous Idealist` | 仁德、人望、汉室正统、强关系绑定 |
| 马腾 | `Commander`，玩家类型强调忠于汉室 | 西北、骑兵、边地生存、忠诚路线 |
| 袁术 | `The Ambitious Powermonger` | 称帝野心、合法性赌博、困难开局 |
| 袁绍 | `The Dragon of the Yuan` | 名门、联盟、河北大势力、宗族声望 |
| 张燕 | 山贼/山地势力路线 | 山地根据地、袭扰、机会主义扩张 |
| 郑姜 | 女 bandit queen 路线 | 非正统权力、山贼同盟、破坏秩序 |
| 孙坚 | 与传国玉玺相关的初始困境 | 家族势力、江东扩张、玉玺选择 |

可以直接学习的实际栏目：

```text
Hero Class
Nickname
Who is he?
Playstyle
Guanxi
Starting Position
Initial Dilemma
What kind of player is this character for?
Further Reading
```

这个类型适合做：

- 双人历史场景的可选角色页。
- 每个角色不只给背景，还给“适合什么策略”。
- 把历史争议转成赛局开局选择，而不是写成单一结论。

## 《Civilization VII》：领袖短传/能力/议程型

来源页面：`Sid Meier's Civilization VII - Leaders`

真实格式特征：

- 领袖页通常包含：短传、`Unique Ability`、`Attributes`、`Agenda`、`Starting Bias`。
- 领袖不只是历史背景，而是一个整局游戏的行为偏好。
- 同一人物还可能有 persona 版本，改变能力和议程。

实际例子索引：

| 领袖 | 实际字段 | 页面呈现的核心 |
|------|----------|----------------|
| Himiko, Queen of Wa | `Friend of Wei`、`Diplomatic`、`Scientific`、`Yamatai` | 联盟、科学、友好关系收益 |
| Himiko, High Shaman | `Miko of Amaterasu`、`Cultural`、`Diplomatic`、`Shaman Queen` | 文化、幸福、祭司/宗教权威 persona |
| Augustus | `Imperium Maius`、`Cultural`、`Expansionist`、`Restitutor Orbis` | 城镇、购买建筑、罗马式扩张秩序 |
| Charlemagne | `Father of Europe`、`Militaristic`、`Scientific`、`The Golden Shepherd` | 骑兵、庆典、科学/军事结合 |
| Genghis Khan | `Chosen of Tengri`、`Expansionist`、`Militaristic`、`Tümen` | 骑兵、军团指挥官、独立势力军事转化 |

官方 Leaders 索引中还能直接看到的实际领袖名单：

Ada Lovelace, Amina, Ashoka, Benjamin Franklin, Catherine the Great, Confucius, Edward Teach, Friedrich, Gilgamesh, Harriet Tubman, Hatshepsut, Ibn Battuta, Isabella, José Rizal, Lafayette, Lakshmibai, Machiavelli, Napoleon, Pachacuti, Sayyida al Hurra, Simón Bolívar, Tecumseh, Trung Trac, Xerxes。

这个类型适合做：

- 裁判人设：短传 + 议程。
- 角色公开卡：身份 + 独特倾向 + 喜好/厌恶。
- 多角色共用同一阵营时，用“议程”区分人物。

## 《Crusader Kings III》：王朝角色/生活方式型

来源页面：`Legends of Crusader Kings III - Qin Guan / Emir Yahya`

真实格式特征：

- 角色卡包含：头衔/称号、难度、Realm、Age、Faith、Dynasty、引语、开局说明、Lifestyle。
- 不是把角色写成一段英雄传，而是放进继承、家族、信仰、生活方式和风险中。
- 官方页面还给“如何玩这个角色”的路线，例如 `Intrigue Lifestyle`、`Wandering Lifestyle`。

详细实际例子：

| 人物 | 实际字段 | 页面呈现的核心 |
|------|----------|----------------|
| Qin Guan | `Gentleman`、`Difficulty: Easy`、Realm: District of Yangzhou、Age: 17、Faith: Daoxue、Dynasty: Qin、Lifestyle: Wandering | 贫困少年、读书/诗歌/军事策略、从游历路线展开 |
| Emir Yahya | `The Duke of Toledo`、`Difficulty: Medium`、Realm: Tulahytula、Age: 53、Faith: Muwalladism、Dynasty: Dhunnunid、Lifestyle: Intrigue | 托莱多危机、家族失势风险、操纵对手与寻找盟友 |

- 让选手知道角色不是自由发言的现代人，而是被制度和身份限制的人。

## 《Age of Empires II: Definitive Edition》：战役钩子型

来源页面：`Age of Empires II: Definitive Edition - Campaigns`

真实格式特征：

- 每个战役以人物名或势力名为标题。
- 文案不是完整传记，而是给玩家一个历史任务。
- 高频结构：危机背景 + 主角登场 + 能否完成任务的疑问句。

实际战役例子索引：

## 《Assassin's Creed》与 Discovery Tour：资料库/博物馆型

来源页面：Ubisoft News `Assassin's Creed Origins - Discovery Tour Shows a Different Side of Ancient Egypt`

真实格式特征：

- Ubisoft 说明 Discovery Tour 借用了系列里的 Animus Database 概念。
- Database 原本记录玩家在游戏中遇到的重要人物、地点和事件。
- Discovery Tour 将复原场景变成无战斗的“living museum”，通过 guided tours 讲历史。

实际样例意义：

| 项目 | 实际呈现方式 |
|------|--------------|
| Animus Database | 人物、地点、事件作为游戏内知识条目 |
| Discovery Tour | 无战斗游览模式，玩家通过导览路线学习历史 |
| Ancient Egypt | 托勒密埃及的城市、人物、建筑、社会生活被拆成可游览知识点 |

这个类型适合做：

- 背景材料中的“可点击人物注释”。
- 不直接服务胜负，但服务沉浸和历史理解。
- 给学生读的材料可以用这种格式：短条目、清楚来源、避免论文腔。

## 《Europa Universalis IV》：国家路线/历史遗产型

来源页面：`Europa Universalis IV - Paradox Interactive`

真实格式特征：

- 重点不是单个人物卡，而是国家、历史遗产、国家理念和早期现代世界。
- 官方介绍强调可以在时间跨度内选择任意日期，用历史君主和领袖开局。
- `national ideas` 代表一个国家的历史遗产和未来野心。

实际例子类型：

| 项目 | 页面呈现方式 |
|------|--------------|
| 历史君主/领袖 | 玩家可以从时间跨度中的任意日期开始，使用历史君主和其他领袖 |
| National Ideas | 随时间采纳，代表历史遗产和未来野心 |
| 时代范围 | 航海发现、宗教战争、革命政府等早期现代史节点 |

这个类型适合做：

- 当人物只是国家路线的代表时，不必写成个人英雄。
- 例如“改革派”“守旧派”“海权派”“财政派”可以写成国家策略，而非单一性格。

## 《Imperator: Rome》：角色权力基础/忠诚风险型

来源页面：`Imperator: Rome - Paradox Interactive`

真实格式特征：

- 官方介绍强调角色拥有会变化的 skills 和 traits。
- 人物会领导国家、治理行省、指挥军队和舰队。
- 不忠的总督或将军可能带着军队反叛。

实际例子类型：

| 项目 | 页面呈现方式 |
|------|--------------|
| Characters | 有变化中的技能和特质 |
| Offices | 领导国家、治理行省、统率军队/舰队 |
| Loyalty risk | 不忠总督或将军会转而反叛，并带走军队 |
| Government forms | 共和国管元老院，君主制管宫廷，部落制回应氏族 |

这个类型适合做：

- 设计隐藏信息：某角色表面忠诚，但权力基础很强。
- 裁判追问可以问“你的方案如何处理将领忠诚/地方军权/家族不满”。

## 对 Axiia Cup 文档的实际建议

如果要写“人物小传”，建议至少保留三层：

```text
人物名
历史身份：一句话，像《信长之野望 出阵》。
角色机制：2-4 个标签，像《三国志 14》或《Civilization VII》。
开局压力：一个必须处理的局势，像《Total War: THREE KINGDOMS》或《Age of Empires II》。
```

更完整版本可以用：

