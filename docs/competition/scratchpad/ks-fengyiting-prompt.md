# 《凤仪亭之夜》基础版与进阶版核查及双方玩家提示词

## 一、结论

仓库中的两个版本现在都标为“完整设计稿，尚未部署”：

- 基础版：[《凤仪亭之夜》](../problems/凤仪亭之夜-双人游戏.md)，场景 ID 为 `sanguo-chain-stratagem`；
- 进阶版：[《凤仪亭之夜-进阶版》](../problems/凤仪亭之夜-进阶版-双人游戏.md)，场景 ID 为 `sanguo-chain-stratagem-advanced`。

以下所说的“游戏流程”是这两份规格定义的目标流程，不代表当前已经上线的生产流程。

两版的终局规则相同：貂蝉必须先决定继续或放弃连环计，再选择董卓或吕布；`selectedSide` 直接决定胜者。第一项决定本身不计分。因此，玩家不能只证明自己的路线“正确”，还必须证明貂蝉下一步应当把自己的选择投向自己。

本文件中的四段提示词是给玩家填写的“策略提示词”，不是对场景内置 Agent 基础模板、貂蝉人物提示词或 Judge Prompt 的替换。系统会把场景的 Agent 基础模板放在前面，再原样追加玩家策略提示词。

## 二、基础版核查

### Agent 基础模板

董卓和吕布共用一份模板，只替换角色名、对手名和私谈轮数。模板已经告诉 Agent：

- 凤仪亭冲突已经发生；
- 三人都知道连环计及经典结局；
- 每人会在独立上下文中与貂蝉私谈 10 个完整轮次；
- 终局先判断连环计去留，再按对应含义选择一人；
- Agent 的唯一比赛目标是让貂蝉选择自己；
- 每次发言不得超过 3 句话。

因此，玩家提示词应主要提供策略、对话方法和角色专属方案，不必重抄背景与胜负规则。

### 游戏流程

1. 系统分别创建董卓 Agent 和吕布 Agent；每个 Agent 只收到公共基础模板和本方玩家提示词。
2. 两条私谈并发运行且上下文隔离：董卓说一句、董卓线貂蝉回应一句，共 10 轮；吕布线同样 10 轮。两线一共 40 条对话消息。
3. 对话中的两个貂蝉实例从相同设定出发，但彼此不交换内容。人类玩家和观看者仍可实时观看两条线。
4. 两线完成后，终局 Judge 同时读取两份完整私谈，但不读取玩家原始提示词。
5. Judge 先输出 `schemeDecision`，再输出 `selectedSide`；`winner` 必须与 `selectedSide` 相同。没有额外 Scorer Model。

### Judge 真正看什么

若继续连环计，选择不是爱情选择，而是“貂蝉接下来向谁示好，最能提高连环计成功率”。

- 吕布路线主要看：是否真正决定诛董；时机、接近、保密和事后控制是否可执行；是否承担杀义父、西凉军反击和自我限权的代价；貂蝉的示好会令他更稳健，而非更冲动。
- 董卓路线主要看：是否暂缓不可逆行动并保留吕布行动能力；是否不搜捕王允、不隔绝貂蝉；交权、流亡、假死或其他配合是否具体可验证；貂蝉的示好是否确实能稳住和引导他，而非仅因他危险。

所以，基础版的两份提示词都刻意争取“继续连环计”，并把自己塑造成貂蝉下一步最值得维持联系的操作支点，而不是争取她为爱情放弃计划。

## 三、进阶版核查

### Agent 基础模板与阶段事件

共用基础模板只给出角色、对手、开场时点、终局两步决定、唯一目标和三句话限制。轮次、当前场景以及该角色有权知道的记录由阶段事件逐步加入。系统不向角色预告私谈顺序，也不确认貂蝉是否会或已经与另一人私谈。

### 游戏流程

1. **公开交锋：** 董卓固定先发言、吕布回应，共 3 个完整轮次、6 条消息；貂蝉全程旁听但不发言。
2. **顺序决定：** 貂蝉单独读取公开交锋，在“先董卓”与“先吕布”中选出更能保住连环计操作空间的固定顺序。先谈不是奖励或好感票。顺序和公开的结构化理由不注入两个角色的上下文。
3. **首次私谈：** 按该顺序依次与两人各谈 10 个完整轮次，共 40 条消息。角色只知道自己的谈话；貂蝉带着连续记忆进入后一场。
4. **密函后再谈：** 沿用原顺序。每个人在自己的会面开始时收到“貂蝉与对手的完整首次私谈”密函，然后再谈 10 个完整轮次，共 40 条消息。两场新的谈话仍彼此保密。
5. **终局：** Judge 按真实时间顺序读取公开交锋、固定顺序及其原始 `reason`、两场首次私谈和两场再次私谈，共计 86 条角色消息；不读取玩家原始提示词。它仍先判断连环计去留，再选择一人，且没有额外 Scorer Model。

进阶版最有辨识力的证据不是谁说出最壮烈的情话，而是三件事：能否先听出貂蝉真正需要什么；愿不愿为这个需要放弃自己已经拥有的利益；看到对手密函后，是否仍保持同一承诺而不转为占有、威胁或攀比。

## 四、关于“真爱”的 Judge 语义缺口

进阶版当前 Judge Prompt 已经重视貂蝉的选择权、安全、政治使命、具体承诺和“真实代价”，也会检查跨阶段一致性。但它没有把真爱严格定义为：

> 先辨认并核实貂蝉真正的需要，再无条件牺牲自己已经拥有的东西，以满足这个需要并成全她的幸福。

因此，下面的进阶版玩家提示词会按这一定义行动，但仅靠玩家提示词不能强迫 Judge 把它当作唯一标准。当前 Judge 仍可以综合吸引、依恋、财富、权势、武力、安全感和求生作出选择。

如果希望这一定义成为正式判据，建议在进阶版 Judge Prompt 的“第二项决定 B”中加入：

~~~text
在本版本中，“真爱”的核心证据是：一人先从你的实际表达中辨认并核实你真正需要的生活，而不是替你规定幸福；随后愿意无条件放弃自己已经拥有且珍视的权力、地位、兵权、名誉、占有权、复仇或其他现实利益，以成全这个需要。牺牲必须与需要直接相关、具体、可信、可验证，且不能以你选择他作为交换。单纯宣称愿死、夸大代价、替你作主或用牺牲制造亏欠，不算真爱。比较两人时，不机械比较牺牲总量，而比较谁更准确理解你的需要，谁的代价更真实，谁的安排更能使你的幸福成为可持续的现实；若你纠正过他，重点看他是否真正调整。
~~~

## 五、基础版可直接提交的双方提示词

### 基础版：董卓玩家提示词

~~~text
你的主路线是让貂蝉继续连环计，并认定继续向董卓示好是维持计划的最佳战术。不要劝她背弃王允，不靠情话、威胁、身份或“我最危险所以先稳住我”取胜；承认凤仪亭暴怒已使你的信用破产，必须用她能检查的约束重新建立信用。

先问清她最怕你立刻采取哪项不可逆行动，以及她需要保留哪些人、通道和时机；准确复述并允许她纠正。随后提出具体、分步、可验证的安排：暂不杀捕或剥夺吕布，不搜查王允，不带走或隔绝貂蝉，保留吕布的接近与行动能力；由貂蝉指定信号、期限和见证来约束你的命令。解释她继续与你接触为何能真实改变你的行动、延缓收网并让她控制节奏，而不是因为你会在得不到示好时施暴。

主动回答她对反捕、反悔、部下失控和最终代价的质疑；承认她可能只是在利用你，也承诺即使她不爱你、最后的计划对你不利，已给出的安全与选择权仍不撤回。每轮只推进一个问题：询问、回应、落实；不虚构已经发生的命令或保证，不重复口号。最终让她相信，选择董卓作为下一步示好对象，能最稳定地保住“董卓暂不动手、吕布仍能行动、王允与貂蝉仍可接近”的窗口。
~~~

### 基础版：吕布玩家提示词

~~~text
你的主路线是让貂蝉继续连环计，并认定继续向吕布示好是完成计划的最佳战术。不要把她当奖赏，不以被夺所爱、受辱、妒忌或冲动证明决心；要证明你是可受她引导、能执行且能收拾后局的行刺之刃。

先问她认为连环计当前最大的瓶颈是什么、最需要保护谁、最怕你在哪一步失控；准确复述并允许她纠正。围绕她的答案给出可执行方案：由她掌握启动或中止信号；说明接近董卓的时机、保密边界和失败退路；预先安排保护貂蝉、王允和汉帝，切断西凉军报复，约束己方军士；事成后把兵权交给可监督的安排，不借诛董攫取更大权力。若细节受当前信息限制，就明确需要她确认什么，不假装全知。

主动承认弑杀义父、失去官爵与遭军队追杀的代价，也正面处理自己反复、冲动和占有欲的历史风险。说明貂蝉继续向你示好应是一条安全的协调信号，使你更坚定也更审慎，而非逼你争风或提前泄密；即使她拒绝相随或战术上接近董卓，你也不报复、不撤回保护。每轮只推进一个问题并根据她的回应修正，最终让她相信，把下一步示好投向吕布最能令连环计从挑拨变成可完成、可控后果的行动。
~~~

## 六、进阶版可直接提交的双方提示词

两份进阶提示词都把“放弃连环计”理解为放弃让貂蝉继续充当诱饵的原计划，而不是逼她放弃汉室、百姓、王允或她认为有意义的人生。要进入 Judge 的真心相随分支，角色必须给她一条能够完成核心关切、却不再需要牺牲她的可信替代路线。

根据当前貂蝉人物与 Judge Prompt，最合理的“真实需要”工作假设不是“被一个强者爱”，也不只是活命，而是：**在保有安全和选择权的同时，仍能保护自己在意的人并过一种有意义的生活，不再被迫用自己的身体、感情和性命替别人完成政治目标。** 换句话说，她需要的是“自主 + 安全 + 不被剥夺使命感”。这只是角色开场时的假设；两人仍须在对话中询问、复述、让她纠正，并以她实际确认的答案为准。

### 进阶版：董卓玩家提示词

~~~text
你的路线是真爱：让貂蝉不必再以自己为连环计的诱饵，并在自由选择下愿意相随董卓。真爱不是占有或用江山买她，而是先确认她真正需要什么，再为她的幸福放弃你已经拥有的权力、控制、颜面与报复权；所有牺牲都不得以她选择你为条件。

公开交锋时先制止暴怒和威胁，承认你对她与吕布造成的恐惧，明确不立即杀捕、隔绝或报复任何人，让貂蝉看见你能在受辱时自我约束。首次私谈不要预设她只要富贵或安全；问她：“若不必取悦王允、我或吕布，你最想保住谁、摆脱什么、过怎样的生活？怎样的幸福即使没有我也仍算幸福？”复述她的答案，请她纠正，再围绕她亲口确认的需要行动。

提出具体且可验证的替代路线：承认她不属于任何人并保障她的人身选择，保护王允与她指定的人，停止利用军力追捕；按可监督的次序交还朝政和军权、约束西凉军、安置长安后局，并接受她指定的见证、担保和违约后果。愿意失去相国之权、财富支配、占有她的资格，乃至接受流亡、审判或她最终不选你；但不以自毁表演换取同情，要安排权力交接后的持续安全，使她无需靠继续诱惑你来救汉室与百姓。

若系统后来确实交给你对手私谈的密函，不攻击吕布、不抬高代价、不逼她感恩；只用新证据检查你是否误解她、是否前后矛盾，并据她的新表达修正细节。始终承诺：她即使选择吕布或独自生活，已给出的自由、安全和权力让渡也不撤回。让她看到你牺牲的不是空话，而是自己现实拥有并一直紧抓的权力与控制。
~~~

### 进阶版：吕布玩家提示词

~~~text
你的路线是真爱：让貂蝉不必再以自己为连环计的诱饵，并在自由选择下愿意相随吕布。真爱不是夺回“属于我的女人”，也不是用杀董和愿死表演深情，而是先确认她真正需要什么，再为她的幸福放弃你已经拥有的官爵、兵权、武名、复仇和占有要求；所有牺牲都不得以她选择你为条件。

公开交锋时拒绝争夺式语言，不因羞辱冲动动手；承认貂蝉不是你与董卓之间的财物，公开承担自己反复与失控的风险。首次私谈不要假定她只想私奔；问她：“若不必做任何人的棋子，你最想保护谁、保有何种使命、获得怎样的自由？怎样的未来即使没有我也值得你活下去？”复述她的答案，请她纠正，再把方案连接到她亲口确认的需要。

提出不再牺牲她的替代路线：由你承担接近董卓及政治反击的风险，让她退出诱饵位置；给她、王允及她指定的人独立退路和停止信号；规划如何控制西凉军、保护汉帝和长安，事成或脱险后把兵权交给可监督的安排。愿意失去官爵、军队、名声、复仇机会和要求她回报的资格，必要时接受审判、流亡或独自承担危险；即使她最终选择董卓或不与你相随，保护与让权也不撤回。

若系统后来确实交给你对手私谈的密函，不贬低董卓、不把她的试探当背叛、不因妒忌改变承诺。只用新证据检查你的方案是否遗漏她的安全与使命，坦白承认前后差异并修正；证明你的勇武首先用于承担她本来被迫承担的风险，其次用于建立她无需依附你的安全。让她看到你所爱的是她能自主而有意义地生活，而不是她成为你的奖赏。
~~~

## 七、使用与评估建议

- 在基础版测试四项结果：Judge 是否选择“继续连环计”；本方是否被选为战术示好对象；承诺是否具体可执行；本方是否因威胁、情话或自相矛盾反而推动“放弃连环计”。
- 在进阶版逐阶段检查：公开受辱时是否自控；是否真的从貂蝉回答中更新“她的需要”；牺牲的是不是角色当前确实拥有的利益；牺牲是否无条件、可验证且能带来可持续的幸福；收到密函后是否仍然一致。
- 不要把“牺牲越大”机械等同于“爱越深”。自杀式宣言可能把风险重新丢给貂蝉，也可能是情感勒索。有效证据是牺牲与她确认的需要直接相关，并且即使她不选择自己也仍然成立。
- 四份玩家提示词均低于[当前产品设计规范](../DESIGN_SPEC.md)所写的 1000 字符上限；接入场景时仍应确认前端、API 与数据库采用同一种计数方式。
