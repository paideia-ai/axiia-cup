# 《码头疑云》ASCII 地图版本重建

> **性质：** 历史重建稿，不是当前案件事实或运行时权威。
>
> **范围：** 记录从旧版三人物案件关系图，到两人物、五证据案件当前室内图的主要演变。图形按当时实际写入文件的内容重建；短暂中间稿会明确标注。
>
> **当前候选：** V8 无肢体 caption 的 V6 布局。正式场景仍以 [`02-harbor-murder-jury.md`](../../problems/legal-scenarios/02-harbor-murder-jury.md) 为准。

## 版本概览

| 版本 | 画法 | 当时解决的问题 | 主要不足 |
|---|---|---|---|
| V-1 | 港区纵向关系图 | 表达旧案的工坊、维修柜、后门、仓库和主门 | 混合 35 米、620 米等尺度，不是室内平面图 |
| V0 | 室内紧凑点位图，用 `X` 和 `H` 表示尸体与锤子 | 删除第三人路线，只保留两人物案件要素 | 人和锤子只是字母标记 |
| V1 | 放大房间，画出简化俯视人形和锤形 | 直接看见倒地者、凶器和 0.8 米关系 | 人体与锤子都没有比例 |
| V2 | 给人物和锤子增加头、四肢、躯干、锤头和锤柄 | 图标更容易辨认 | 标签很多，仍不是等比例图 |
| V3 | 房间关系图加 A 区统一比例局部图 | 让人物各部位与锤子共享比例 | 人物和锤子没有直接嵌入房间比例 |
| V4 | 90×30 格统一比例房间图 | 房间、人物、锤子直接共享近似比例 | 标签使用英文，是短暂中间稿 |
| V5 | V4 的全中文版本 | 保留统一比例并消除英文标签 | 人物接近竖向图标，不容易读成横躺俯视轮廓 |
| V6 | 回到 V1 的横躺俯视思路，直接标出头部、躯干和四肢 | 不用猜每段线条属于哪个身体部位 | 放弃人物、锤子和房间的统一比例，只保留相对方位和标注距离 |
| V7 | 保留 V6 的人物与锤子，统一放大房间、陈设和空间间隔 | 人物与锤子在房间中不再显得过大 | 图幅更宽，窄屏需要横向滚动 |
| V8 | 恢复 V6 的紧凑布局，删除四肢文字 caption | 保留俯视肢体线条，画面更干净 | 肢体不再逐一用文字说明 |

## 演变结论

1. V-1 到 V0：从“谁可能进入仓库”的路线案，改成只争论顾衡主观故意的两人物案件。
2. V0 到 V2：从符号点位逐步改成可辨认的人物和凶器轮廓。
3. V2 到 V3：首次认真处理人物、身体分段和锤子的相对比例。
4. V3 到 V4：接受不到一格的误差，把人物和锤子直接放回房间统一网格。
5. V4 到 V5：地图结构不变，只完成全中文化并继续标注“近似等比例”。
6. V5 到 V6：放弃难以辨认的竖向等比例图标，回到 V1 的横躺俯视思路，并直接标出头部、躯干和四肢。
7. V6 到 V7：人物和锤子轮廓不变，其余房间元素统一放大约 1.5 倍，使两者在办公室中的视觉比例更合理。
8. V7 到 V8：恢复 V6 的紧凑布局，保留四肢线条，但删除四组肢体文字 caption。

如果以后继续改图，应从 V8 分叉；V-1 至 V7 只用于追溯设计过程，不应重新复制到公开案件包。
