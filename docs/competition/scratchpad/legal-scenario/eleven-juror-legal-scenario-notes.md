# 十一人陪审团法律场景讨论记录

> **归档说明：** 本文保留用户讨论与早期取舍。已经确定的案件、九名 NPC persona、行动次数、五轮流程、信息边界和 V2 契约见 [`02-harbor-murder-jury.md`](../../problems/legal-scenarios/02-harbor-murder-jury.md)。

## 当前担忧和决定

### 1. 案件必须 internally consistent

案件中的证据不能互相矛盾，整体至少要达到一般推理小说的水准。

可以考虑三种办法：

- 继承一部现有推理小说的剧情；
- 继承一部现有电影（例如《十二怒汉》）的案件剧情；
- 把原创案件设置得足够简单，从而降低出现逻辑漏洞的风险。

### 2. 对抗双方

此前把对抗双方写成了控辩律师，这是错误的。两名玩家都应当是陪审员，但分别持有相反的初始立场：

- 一方主张现有证据已经足以定罪；
- 另一方主张案件仍然存在合理怀疑。

两人是在陪审团内部说服其他陪审员，不负责举证、询问证人或完成律师式庭审程序。

### 3. 场景必须包含 tool call

tool call 的种类不再预先限制为三种。以下行动都可以进入计划，之后再根据可玩性、成本和实现复杂度决定哪些进入首版：

- 拆阅一份密封证据；
- 请求进行一次秘密陪审团投票；
- 要求重新宣读某段证词；
- 检查或演示一件物证；
- 申请排除某项证据；
- 决定是否传唤一名证人；
- 提出一份范围更窄的禁令方案；
- 修改一项重整计划；
- 使用或保留一次陪审员回避机会。

### 4. 十一名陪审员都是 Agent

采用“所有 Agent 都是陪审员”的方向，避免设计完整法庭程序，例如 direct examination 和 cross examination。

案件材料与既有证词在游戏开始时已经形成。玩家面对的是陪审团审议，而不是完整庭审。

暂定席位构成为：

- 两名玩家控制的立场型陪审员；
- 九名由系统控制、拥有不同人物背景和判断倾向的陪审员。

### 5. 发言方式

- 处于对抗面的两方每轮一定发言；
- 每轮都询问九名 NPC 陪审员一次，让每个人根据自己的 prompt 和当前局势选择申请发言或保持沉默；
- 接受由此产生的较多模型调用；五轮仅发言意愿判断就会产生 45 次调用；
- 每轮最多选择三名 NPC 实际公开发言；如果申请者不足三名，就让所有申请者发言，不强行补足；
- 超过三人申请时，不使用另一个 LLM 选择发言者，而按照“紧急申请优先、上一轮未发言者优先、累计发言较少者优先、轮换座次优先”的公开确定性规则选出三人。

### 6. 判决方式

按照人数多寡投票决定结果，不采用现代英美刑事陪审团必须一致同意的规则。十一人制不会出现平票；若采用简单多数，胜负线就是六票。

需要寻找古希腊、古罗马或其他历史制度中以多数票作出裁决的陪审团制度，并考虑把故事放在相应时代。

### 7. 陪审员人物设计

参考《十二怒汉》的启示：

- 每名陪审员都有自己的身份和背景；
- 每名陪审员对不同问题敏感，例如时间线、证人可信度、物证、程序问题或多数压力；
- 通过为每名陪审员编写独立提示词实现差异。

### 8. 不设置初始投票

游戏开始时不公布，也不预设一个玩家可见的起始票型。双方先开始辩论。

“进行全场不记名投票”可以作为一个 tool call。只有使用该能力后，双方才知道在场所有人的当前立场。

### 9. 事实和证据完全公开

案件证据和事实对所有参与者完全公开。游戏不依赖隐藏真相或隐藏证据权重。

正式案件采用 8 项编号证据，参考《12 Angry AI Agents》附录 B 的材料规模和组织格式，但使用原创案件内容。

### 10. 暂定游戏行动

#### 全场不记名投票

- 使用次数尚未最终决定；“每方最多三次”保留为上限候选，但需要先测算九名 NPC 每次独立投票所产生的模型调用成本；
- 使用后得知在场所有人的当前立场；
- 默认只显示总票数，不显示个人选择。

#### 全场记名投票并申请提前终局

- 对抗双方可以要求全场进行记名投票；
- 如果支持提前终局的人数超过某个门槛，例如二分之一或三分之二，则立刻开始最终判决投票；
- 具体门槛尚未决定。

#### 证据检查行动

- 可以包含重新宣读证词、检查物证或重建时间线等行动；
- 是否限制次数仍需通过试玩决定；
- 这些行动只能重新组织或澄清开局已经公开的材料，不能凭空引入决定胜负的新证据。

#### 一对一私聊

- 这是必须存在的 tool call；
- 对抗双方各可以在任意时点选择其余陪审员中的一位；
- 私聊进行三个完整往返；一个完整往返是玩家说一次、目标陪审员回应一次，因此共六次发言；
- 私聊是否发生、对象是谁以及具体内容，都不向其他游戏角色公开；
- 叙事上可以表现为两人暂时离席，例如在去洗手间、取水或走廊等待时进行短暂交谈，参考《十二怒汉》中脱离全场讨论的私下交流场景。

### 11. 暂定回合结构

- 一共五轮；
- 每轮两名对抗方一定发言；
- 其余陪审员自行选择是否发言；
- 中途没有系统强制投票，除非有人使用投票类 tool call；
- 五轮结束后一定开始最终判决投票；
- 整体节奏类似狼人杀；
- 发言顺序仍需进一步讨论。

### 12. 陪审员模型

可以先让每名陪审员使用不同模型，同时每个人拥有不同提示词。具体效果通过 benchmark 再决定。

### 14. 第一版案件骨架

已经决定继续使用原创现代版“码头疑云”，副标题为“七号仓命案”，并完成第一版八项证据：

- 公开案件包：[`harbor-murder-public-case-v0.md`](./harbor-murder-public-case-v0.md)

八项证据分别覆盖：双方潜在动机、顾衡到场和争执、人为停电、罗启明门禁卡、顾衡手机 Wi-Fi、维修锤混合 DNA、衣袖血点与死亡时间、车辆记录和顾衡改口。

作者真相设为顾衡利用偷来的门禁卡制造第三人进入假象并杀害纪川。这个真相只用于一致性审计，不进入任何 Agent prompt，不参与投票或评分。
