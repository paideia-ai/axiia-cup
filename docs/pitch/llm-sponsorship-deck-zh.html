简历筛不出的人才信号

排行榜衡量的不是 GPU 或 Python，而是：

  • 约束下的提示词工程
    1000 字符，双角色，随机信息分配
  • 策略阅读力
    顶尖玩家攻击裁判偏好，而非历史真实性

    双角色迫使从两个对立视角建模裁判

    3 句/轮硬约束是最大判别器

05

裁判偏差现象

一个活的 Benchmark

同一段辩论记录，DeepSeek 判、GPT-5.4 判、Claude Opus 判 — 赢家不同。

这不是 bug。这是一个研究发现。

标准 benchmark 不测的东西：

  • 你的模型评判时偏好文采还是证据？
  • 你的模型对改革派 vs 保守派有系统性偏倚？
  • 你模型的判断力和它作为对话者的行为是否一致？
  • 对相同输入反复评判的一致性如何？
05

裁判一致性指数

Judge Consistency Index — 价值对齐 Benchmark

N 份相同对战记录 × M 个裁判模型

模型内一致性
同一记录两次评判，结果是否一致？
模型间一致性
不同模型是否收敛到相同判决？
位置偏倚
交换角色 A/B 标签后判决是否改变？
推理质量
文字推理是否支持数值评分？

不测模型知道什么，测模型如何评判对立论点。现有 benchmark 都没有在对抗性、人类优化的输入上做这件事。
