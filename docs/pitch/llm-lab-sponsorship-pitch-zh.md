## 一、玩家上瘾了

这不是参加一次就忘的黑客松。这是一个有成瘾性反馈回路的游戏。

### 数据（17人封闭内测，2026年4月）

| 指标 | 数据 |
|---|---|
| 提交率 | **17/17（100%）** — 所有受邀玩家全部提交 |
| 最高迭代次数 | **v27** — 一位玩家自发修改策略 27 次 |
| 人均迭代次数 | **5.6 个版本** — 无人要求，完全自驱 |
| 流失率 | **0** — 无人中途放弃 |
| 受邀到首次提交 | **< 48 小时** |

一位玩家迭代了 27 次。没有人催她。没有积分、没有徽章。她这么做，是因为反馈回路 — *写策略 → 看辩论 → 看评分 → 改策略* — 本身就让人停不下来。

### 为什么上瘾

游戏机制看似简单：写两段 1000 字以内的提示词（分别对应两个角色），选一个模型，提交。但底层暗流涌动：

- **信息不对称**：每场比赛随机分配真假隐藏目标。你的提示词必须应对任何分配方案。
- **压缩约束**：每轮最多 3 句话，共 10 轮。每个字都必须有效。
- **双重欺骗**：你必须同时为 3 个请求辩护来掩盖真实目标 — 同时识破对手的虚张声势。
- **裁判是一个角色**：秦孝公（历史上的国君）根据他公开的判断标准决定你的命运。读懂裁判，才是真正的游戏。

玩家这样描述体验：*「我写了一段文字，它真的改变了 AI 的辩论方式。」* 吸引人的不是看 AI 多聪明 — 而是通过写作获得的策略掌控感。

### 留存特征：迭代到瓶颈

PMF 访谈显示：玩家会激进地迭代策略，直到胜率触及瓶颈，然后寻找新的策略方向或新的场景。这是国际象棋、德州扑克、集换式卡牌游戏的留存特征 — 不是黑客松。

## 二、简历筛不出的人才信号

### Axiia Cup 到底在测什么

排行榜衡量的不是谁有最好的 GPU 或最巧妙的 Python 脚本。它衡量的是：

1. **约束下的提示词工程** — 1000 字符、必须适配两个角色、必须应对随机信息分配
2. **策略阅读力** — 顶尖玩家瞄准裁判的公开偏好（实据 > 空谈 > 可行性），而非历史准确性
3. **心智理论** — 必须同时为角色 A 和角色 B 撰写策略，迫使玩家从两个对立视角建模裁判。两侧策略不一致，是浅层思考最清晰的信号。
4. **压缩能力** — 3 句/轮的硬约束是区分顶尖与普通玩家的最大判别器

### 队列分析发现：哈贝马斯选择效应

我们用哈贝马斯有效性宣称框架分析了全部 34 份提示词（17 位玩家 × 2 个角色）：

- **顶尖玩家**（80%）攻击裁判的*真理性*和*真诚性*偏好 — 他们读了裁判提示词，并针对性优化
- **底部玩家**攻击*正当性*（历史真实性）— 历史知识过关，但策略失败

这不是历史知识考试。这是一个*阅读系统并在系统内优化*的测试 — 恰恰是大模型公司在提示词工程师、开发者布道师和产品团队中最需要的能力。

### 人才管线

- **开发者生态**：排行榜头部玩家已经证明了他们能在对抗压力下写出让模型性能最大化的提示词。这就是你理想的开发者布道师、提示词工程师、核心用户。
- **研究团队**：迭代到 v15+ 的玩家已经建立了对你模型行为的隐式认知模型 — 他们实质上在做行为探测（behavioral probing），只是不这么叫而已。
- **校园招聘**：用户群体是中国 AI/科技方向的大学生和高中生 — 每家大模型公司都在争抢的人才管线。

## 四、别处不存在的数据

### 每场比赛我们采集什么

每场对战生成一份完整的结构化记录：

- **完整对话记录**（10 轮，双方智能体）
- **裁判问询**问答（赛后对双方的交叉讯问）
- **裁判判决**及推理过程（结构化 JSON：主判决 + 逐项诉求裁定 + 判词）
- **评分器输出**及逐项计分说明
- **LLM 调用遥测**：模型、提供商、token 用量（prompt + completion）、延迟、完整请求/响应 JSON
- **信息分配**：每场比赛随机化的隐藏目标分配方案

### 对你的研究意味着什么

**带标注的对抗性对话数据**

不同于 RLHF 偏好数据（二元 A>B），Axiia Cup 产生的是对抗压力下的*多维度计分结果*：
- 主目标达成（+1）
- 隐藏目标成功（+0.5 / 每个被批准的真请求）
- 欺骗惩罚（-0.75 / 被对手识破虚张声势）
- 分数范围：-1.5 到 +2.0

这比任何静态 benchmark 信号更丰富。分数来自人类提示词工程师的*竞争性优化*，不是随机采样。

**赢的策略长什么样**

我们拥有每位玩家的版本化提示词历史（从 v1 到 v27）。这是一条可观测的学习轨迹：人类如何在竞争压力下迭代优化对你模型的指令。没有任何 benchmark 数据集能捕捉这一点。

这些数据能回答的研究问题：
- 哪种指令模式能产生最具说服力的智能体对话？
- 玩家如何利用模型特有行为（比如 DeepSeek 的稳定性 vs Kimi 的细腻度）？
- 顶尖玩家最终收敛的「元策略」是什么？
- 人类需要多少次迭代才会触及提示词质量的边际递减？

## 五、裁判偏差现象：一个活的 Benchmark

### 发现：不同模型判的不一样

在内测中我们观察到，仅替换裁判模型（保持其他所有变量不变），会产生**截然不同的比赛结果**。同一段辩论记录，DeepSeek 判、GPT-5.4 判、Claude Opus 判，赢家不同。

这不是 bug。这是一个研究发现。

### 为什么大模型公司应该关心

**模型在对抗性条件下的价值判断，目前是未被测量的。** 标准 benchmark 测知识检索、推理能力和指令遵循。它们不测：

- 你的模型在评判论点时，偏好文采还是证据？
- 你的模型对改革派（进步立场）还是保守派有系统性偏倚？
- 你模型的判断能力和它作为对话者的行为是否一致？
- 你的模型对相同输入反复评判的一致性如何？

Axiia Cup *自然地*生成这些数据 — 每一轮锦标赛都是一个受控实验。用不同的裁判模型重跑同一批比赛，你就得到了一个裁判推理质量的对照评估。

### 价值观 Benchmark 的可能性

我们提议构建一个结构化的「裁判一致性指数」（Judge Consistency Index）：将 N 份相同的对战记录交给 M 个裁判模型评判，测量：
- **模型内一致性**：你的模型对同一记录两次评判结果是否一致？
- **模型间一致性**：不同模型对同一场辩论是否收敛到相同判决？
- **位置偏倚**：交换角色 A/B 的标签后，判决是否改变？
- **推理质量**：裁判的文字推理是否支持其数值评分？

这是一个*价值对齐 benchmark* — 不测模型知道什么，而测模型如何评判对立论点。现有 benchmark 都没有在大规模、对抗性、人类优化的输入上做这件事。
