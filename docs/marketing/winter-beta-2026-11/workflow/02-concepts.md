# 五张二创内容方案

目前交付第1、2、5张；第3、4张保留为已选方案。各张共用本期宣传文案、细高底栏字形及真实二维码工作流，画幅按对应方案安排。

## 1. 大王……我想变法……

参考《灌篮高手》“教练，我想打篮球”的全景。三井寿替换为商鞅，穿秦国时代衣袍，跪坐在右下前景、低头弓背；安西教练替换为左侧站立的秦孝公。朝臣在背景旁观，甘龙是一位皱眉的老臣。

体育馆替换为高大空旷的秦国朝堂，保留上方大量建筑空间、下方集中人物的布局。高位椭圆气泡竖排写：

```text
大王……
我想变法……
```

已交付：[竖版成品](../assets/final/01-shangyang.png)。

## 2. 老实西进，很枯燥吧？

参考久留美的笑脸与黑色气泡。保留短发、大眼睛、歪头、微张嘴和带诱惑意味的笑容，服饰改成日本战国说客装束，向画外的明智光秀进言。

人物在右，黑色云朵气泡在左；背景用军帐和行军地图交代语境，地图路线转向“京都”。气泡内白字：

```text
老实西进，
很枯燥吧？
```

已交付：[竖版成品](../assets/final/02-westward.png)。

## 3. 你也来找貂蝉私聊？

参考 JOJO 两人相向走近的单格，保留倾斜视角、夸张步幅、近大远小和拟声字。

近景背对观众者替换为董卓；迎面走来者替换为戴雉鸡翎、穿甲胄、持方天画戟的吕布。凤仪亭庭院远处的貂蝉看着二人。

董卓：“你也来找貂蝉私聊？”

吕布：“不走近一点，怎么知道你背着我承诺了什么。”

## 4. 第38版 prompt：燃尽了

参考矢吹丈坐在拳击台角落的“燃尽了”。保留低头、双臂垂落、瘫坐小凳的姿势，大量留白和粗重排线。

人物是一名戴耳机的参赛选手，脚边放打开的笔记本电脑和揉皱的策略稿。电脑页面标题为“策略 v38”。

主文案：“我只是把『一定要赢』改成了『请务必赢』。”

小字：“凌晨 4:37，第 38 版 prompt。”

## 5. 奉先，你的是我的

参考胖虎、大雄、小夫的单格，保留简洁圆润的画法和三人位置关系。

中间胖虎的位置替换为董卓：体型宽大、留胡须、穿汉末官服，眯眼张嘴，说得理所当然。右侧大雄的位置替换为吕布：戴雉鸡翎、穿甲胄，圆瞪双眼、神情委屈、额头一滴汗。左侧小夫的位置明确替换为貂蝉，安静旁观。

背景用少量亭柱和栏杆交代凤仪亭。只有董卓说话：

```text
奉先，我们是父子吧？
你的是我的，我的还是我的。
```

貂蝉和吕布均无台词。貂蝉不设“嗯。”气泡、思考气泡或旁白。
