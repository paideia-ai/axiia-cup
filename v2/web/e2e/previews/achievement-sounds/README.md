## 文件与复现

- `manifest.json`：供试听界面加载的十项数组；`id`、`name`、`description`、`duration`、`file`、`character`。
- `*.wav`：44,100 Hz、双声道、16 位有符号 PCM WAV；时长 0.65–1.75 秒。
- `render.py`：Python 3
  标准库合成器；固定随机种子，无第三方包、网络请求或外部素材。
- `metrics.json`：对实际编码后的 WAV
  进行测量，包含文件哈希、头信息、峰值、RMS、首尾静音和削波检查。
- `verification.json`：重复生成的一致性，以及独立 FFmpeg
  响度和真峰值检查。FFmpeg 不是生成依赖。

在本目录执行：

```sh
python3 render.py
python3 render.py --check
```

生成时覆盖本目录十个音频及对应 manifest、metrics；`--check`
只读验证，且比较已记录的哈希与实际文件。

## 电平与尾音

音符使用平滑起音、指数衰减和尾部缓降；末尾至少保留 18 毫秒数字静音。输出保留至少
6 dB 的样本峰值余量，没有削波。每段按有效声音窗口的 RMS
约束响度，而不是把停顿和结尾静音计算为需要补偿的音量。

`active_rms_dbfs` 使用高于 −45 dBFS 的 20 毫秒窗口，目标约 −23
dBFS。它是短提示音的能量比较值，不是 LUFS。FFmpeg 的短音频综合 LUFS
仅用作交叉检查；此长度下门限与不同尾音比例会影响结果，不能直接等同于主观音量。`last_50ms_rms_dbfs`
为 `null` 代表数字静音。

默认建议从 01 或 05 开始试听；07 更有仪式感，10
最克制。试听页面的音量控制作用于所有方案，选定后仍可单独微调产品播放音量。
