# 智能体 identity page 本地预览

从 `v2/web` 启动：

```sh
deno install --frozen
deno run -A npm:storybook dev -p 6231 --host 0.0.0.0 --ci
```

打开
<http://localhost:6231/?path=/story/agents-identity-review--owner-comparison>。
顶部导航可进入自己的主页、NPC 对局、其他玩家对局、赛事排名和场景介绍。
所有数据均为本地示例；不访问生产后端，不保存策略、不创建真实对局。

检查路径：

- 自己的主页：版本卡中的战绩仍可点击，版本对比可展开；没有独立胜率卡、底部对战列表。
- 玩家对局 #9002：参与方卡片 → 智能体资料。v1/#466
  置顶并标为本场对局版本，v2/#477
  也平铺显示胜率；无提示词、下拉框和版本对比。点击任一版本进入历史，可翻页。
- NPC 对局 #9001：参与方卡片 →
  单个当场配置，显示当时提示词和模型。点击配置进入历史。
- 赛事 #2：点击提交版本
  #466，身份页置顶并标为赛事提交版本，而非当前参赛标记或最新版本。
- 场景介绍和出战面板：没有 NPC 资料入口。

生产前端的 NPC 身份页依赖后端支持 `matchID` 查询与 `sourceMatchID` 回传。
